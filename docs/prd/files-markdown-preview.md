# files-markdown-preview

**Files 编辑器 Markdown / SVG 预览**

## Problem Statement

在 Files Tab 里打开 README、文档等 Markdown 文件时只能看到源码，想确认渲染效果（表格、图片、层级）得切去别的工具，写文档的「所见」链路断了。打开 SVG 时同样只能看 XML 源码，无法立刻核对图形。

## Solution

Markdown 与 SVG 文件的工具栏出现「编辑 ↔ 预览」两态切换：编辑态还是原来的 CodeMirror。Markdown 预览态把正文换成排版后的富文本（GFM 语法、代码块、表格、相对路径与网络图片），文首的 frontmatter（`---` 围起的 YAML 元数据）显示成正文最上方的键值表，正文可选中复制，代码块悬停时右上角出复制钮（复制代码原文，成功后图标换勾片刻），Cmd+F 在排版后的正文里查找并高亮（与编辑态共用一个查找栏，切换不关、不清空）；SVG 预览态把源码画成图形，并在内容区右上角显示像素宽高（与位图预览同一套角标）。默认进预览态（新建的空文件进编辑态），切换状态会话内保持。在编辑与预览之间切换时停在同一处内容：预览的每一块都记得自己来自源码第几行，两态按此对应；换到别的文档从头开始，切回来回到上次看的位置（规则见 `files-tab.md`「阅读位置」）。Markdown 预览的正文左侧有目录（同飞书文档：盖在正文左侧的留白里、不把正文挤到一边；目录钮开关侧边的目录，地方不够时侧边隐去；侧边没显示时悬停目录钮浮出抽屉、离开即收）：列出文中各级标题、按嵌套关系缩进，点一行就跳到那个标题，正文滚到哪一节哪一行点亮；目录与 PDF / PPT 的缩略图共用面包屑前那颗开关与开关状态，文中没有标题时目录与开关都不出。CSV / TSV 也用同一两态，预览是表格（见 `files-xlsx-preview.md`）。

## User Stories

1. As a 开发者, I want 打开 .md 文件时工具栏出现预览切换钮, so that 我能一键在源码与渲染结果间切换
2. As a 开发者, I want 预览渲染 GFM（表格 / 任务列表 / 删除线 / 自动链接）, so that GitHub 风格的文档所见即所得
3. As a 开发者, I want 预览里的相对路径图片与网络图片（徽章、外链截图）正常显示, so that README 里的图不是裂图
4. As a 开发者, I want 点击预览里的外部链接用系统浏览器打开, so that 应用内不会被导航走
5. As a 开发者, I want 切到预览前自动保存, so that 预览内容与磁盘一致
6. As a 开发者, I want 预览的配色排版随应用主题, so that 深色下不会出现刺眼的白底
7. As a 开发者, I want 非 Markdown / SVG / CSV 文件的工具栏没有该按钮, so that 界面不被无关控件污染
8. As a 开发者, I want 切换文件后预览态保持, so that 连续浏览多个文档不用反复点切换
9. As a 开发者, I want 文档里夹的 HTML（`<br>`、`<details>`、`<kbd>`、带宽度的 `<img>` 等）像在 GitHub 上一样排版、但脚本不被执行, so that README 看起来和 GitHub 上一致，打开陌生仓库的 md 也不会带来脚本注入
10. As a 开发者, I want 打开 .svg 文件时工具栏出现同样的预览切换钮, so that 我能在 XML 源码与图形之间切换
11. As a 开发者, I want SVG 预览不执行文件里的脚本, so that 打开陌生仓库的图标不会带来脚本注入
12. As a 开发者, I want SVG 预览内容区右上角显示像素宽高, so that 我能确认图标实际尺寸
13. As a 开发者, I want SVG 预览与位图共用缩放 / 滚轮或拖拽平移 / 方向键切图, so that 看图标和看 PNG 是同一套操作
14. As a 开发者, I want 能选中并复制 Markdown 预览里的文字, so that 能摘录文档内容
15. As a 开发者, I want 在 Markdown 预览里 Cmd+F 查找，命中标黄、当前命中标橙并滚过去, so that 不切回源码也能在文档里找东西，手感同 PDF / PPT
16. As a 开发者, I want 编辑与预览之间切换时查找栏不关、查询与选项都在, so that 同一个文件里找同一个词不用重输
17. As a 开发者, I want 在编辑与预览之间切换时停在同一处内容, so that 源码里改完切过去就看到这一段的效果，在预览里看到要改的地方切回去就在眼前
18. As a 开发者, I want 换到别的文档时预览从头开始、切回来回到上次看的位置, so that 来回对照几篇文档不用重新找
19. As a 开发者, I want 悬停代码块时右上角出复制钮、点一下复制整段代码并换勾示意, so that 抄命令或示例代码不用手动拖选，也知道复制成功了
20. As a 开发者, I want 文档开头的 frontmatter（标题、标签、日期等元数据）在预览里显示成一张键值表, so that 元数据一目了然，不会被误排成一条分割线加一个挤成一行的大标题
21. As a 开发者, I want Markdown 预览左侧列出文中各级标题、按层级缩进, so that 长文档的结构一眼看清
22. As a 开发者, I want 点目录里的标题就跳过去、正文滚到哪一节目录就点亮哪一行, so that 在长文档里来回找段落不用手动滚，也随时知道自己读到哪了
23. As a 开发者, I want 目录用面包屑前的开关收起、开关与 PDF / PPT 的缩略图共用, so that 想专心看正文时能腾出宽度，几种文档的左侧栏习惯一致
24. As a 开发者, I want 侧边目录没显示时悬停目录钮就浮出目录、移开即收, so that 临时看一眼结构不必把侧边目录开出来，窄栏里也能用目录

## Implementation Decisions

- Markdown 渲染用 `react-markdown` + `remark-gfm`。原始 HTML 接 `rehype-raw` 解析成元素，紧接 `rehype-sanitize` 按默认白名单（即 GitHub 的规则）净化：脚本、事件属性、`style`、非 http(s) / mailto 等协议的链接去掉，`id` / `name` 加 `user-content-` 前缀防 DOM 劫持；净化放在最后一个引入外来内容的步骤之后。解析与净化都保留源码位置，源码行标注排在净化之后。行内与块按 HTML 规范的 phrasing content 判定（`hast-util-phrasing`，只看标签名），源码行标注与查找分块共用这一个判定。HTML 写的 `<img>`、`<a>` 与 Markdown 语法的走同一套相对路径图片与链接拦截。
- frontmatter：`remark-frontmatter` 只认文首 `---` 围起的 YAML（同 GitHub、VS Code），不认 TOML 的 `+++`。表格对齐 VS Code 的预览，每行一个键（`tbody` 里的 `th`，不折行）一个值；列表画成每行一项的嵌套表，嵌套的键值对画成嵌套的键值表，空列表、空键值对与空值留空。YAML 用 `yaml` 解析，取值直接读语法树：标量显示写下的字面（`1.10`、`0x1F`、`~` 不换算），键序照原文，别名写作 `*名字`、不展开（避免自引用无限展开）。写错的 YAML（含重复的键）或不是键值对的（列表、纯文字）原样显示成 YAML 代码块，与围栏代码块走同一个转换（同样有复制钮）；空的（含只有注释的）不显示。转换在 Markdown 语法树转元素那一步（remark-rehype 的 `yaml` 处理），值只生成文字节点，不经原始 HTML 解析；表格与代码块带 frontmatter 的源码位置，阅读位置与查找照常。表格只用 prose 已有的表格样式，补上行表头的留白、字重与配色，嵌套的表不留表格外边距。
- 排版用 `@tailwindcss/typography` 的 prose 类，色板通过官方 `--tw-prose-*` 变量对齐工作区 token（随应用主题），代码块用 `--font-mono`。
- SVG 预览用 `<img>` + `data:image/svg+xml`（CSP 已放行 `data:`），不当 inline XML，脚本不执行；放大时按新尺寸重新栅格化矢量，任何倍率清晰。打开分流仍为 text。
- 两态（编辑 / 预览）而非 WebStorm 三态分屏；状态会话内保持、不落盘，默认预览、新建文件时切回编辑。Markdown、SVG 与 CSV 共用同一开关；开着 Editor Tab 分栏时每栏各一个，同一个文件可一栏编辑、一栏预览（见 `files-editor-tabs.md`）。
- 切换钮在 Files 工具栏右侧钮区最左，与「最近打开 / 在文件树中显示 / …」以既有 1×12px `--border-input` 竖线隔成单独一组（同「显示文件树」）。
- 相对路径图片：按当前文件目录解析、限制在根内，经既有 dc-media 协议流式读取（CSP `img-src` 放行 `dc-media:`）。越界或非图片扩展名不渲染。
- 网络图片：http / https 地址照原样交给 `<img>` 加载（CSP `img-src` 放行 `https:` `http:`，同 GitHub，http 图片也显示）；本机与服务器上的文件一样。
- 链接一律拦截默认跳转：http/https/mailto 交 `shell.openExternal`（复用既有 IPC），锚点与相对链接不动作。
- 切到预览前 flush 保存（与「离开 Files Tab 即保存」同语义）。
- 选中：应用全局禁选，Markdown 预览的正文容器单独放开；容器可聚焦，点进正文后 Cmd+F / Esc 归本预览，PageUp / PageDown 原生滚动。
- 代码块复制：react-markdown 的 `pre` 外包一层定位容器，复制钮盖在右上角、悬停代码块时渐显；钮放在 `pre` 之外，不随代码横向滚动；prose 去掉正文首尾块外边距的规则落在容器上，替容器里的 `pre` 补上。复制的是代码原文：由语法树取文字（`hast-util-to-string`），去掉代码块转成元素时末尾补的换行，同 GitHub；原始 HTML 写的 `<pre>` 同样有钮。复制钮用共用组件（`ui/copy-button` 的 `CopyButton`，与改动块小窗的「复制旧文本」同一个），成功后图标换勾 1 秒（DESIGN.md「操作结果的反馈」的例外）；勾在期间鼠标移开钮也留着；勾收起时鼠标还在就换回复制图标，已移开则钮带着勾淡出、下次悬停进来才换回，淡出途中不闪回复制图标。钮只有图标没有文字，不进查找、不随选中的正文复制；源码行仍标在 `pre` 上。
- 查找：查找会话跟着文件走（规则见 `files-tab.md`「编辑器内查找」）——编辑与预览共用一份（开着与否、查询、区分大小写 / 全词 / 正则），切换不关、不清空、不抢焦点；SVG 预览没有查找，查找栏先藏起、切回编辑原样出现。查找栏同编辑器（`FindBar`，含正则开关，坏正则红字提示），匹配规则与表格、PPT 共用（`lib/text-find`，正则标志同编辑器）；Cmd+F 打开、Esc 关闭复用预览的键盘外壳（不给缩放回调，缩放键不接）。找的是排版后的页面文字：正文按块（段落、标题、列表项、表格格子、代码块）分段，块内跨行内元素（粗体、链接、行内代码）可连着命中，块与块之间不相连；代码块外连续的空格、换行（源码折行、CRLF）按显示的一个空格找，代码块里空白原样。块间排版换行与只给读屏的隐藏文字（GFM 脚注区标题）不算。高亮同 PPT 走 CSS Custom Highlight（与 PPT 共用同一对命中 / 当前命中），不改页面；首个命中取每轮查找开始时（打开、改查询或选项、从编辑态切过来）视口顶边及之后的第一个；两态的命中不一一对应，切换后从新视图的视口顶边重新数（两态已按内容对齐，起点是同一处），上一个 / 下一个循环，当前命中滚到视口正中。同表格 / PPT，打开查找（或正文变了）时建一次文字索引，每次输入只在索引里匹配；正文渲染只随内容变，查找打字不会让整篇重新解析。
- 阅读位置（规则见 `files-tab.md`「阅读位置」）：预览与编辑器共用「视口顶边所在的源码行」。渲染时用一个 rehype 插件给每个块元素标上源码起始行（`data-line`，同 VS Code 的 Markdown 预览），预览以这些块为对应点分段换算：行落在两块之间按高度比例插值，不按源码顺序排的块（GFM 脚注区）跳过；块的位置随页面排版缓存，页面尺寸一变（图片加载、拖窗口）重算。预览按文件重挂，换文件从头开始；图片在视口上方后加载撑高页面时，由浏览器原生的滚动锚定保持眼前的内容不动。
- 目录：样式与版式参照飞书文档的目录（与正文同底、无分隔线、当前标题只变字色，视觉见 DESIGN.md）。不占位：放在正文滚动区里吸顶的零高层上，盖在正文左侧的留白里，留白够宽时开合不挪正文；不够宽时正文右让、变窄，再窄目录也收窄，两者都到最窄仍放不下时不显示侧边的目录。目录钮开关的是侧边的目录，宽窄只决定它显示与否、不改开关：宽屏开着缩到窄屏，侧边的目录隐去，放宽了回来；放不下侧边时点钮不响应，钮也不点亮（钮只在侧边的目录显示着时点亮）。侧边的目录没显示时（收着或放不下），鼠标进了目录钮即从钮下方临时浮出抽屉、没有延迟，离开钮与抽屉即收起（从钮移到抽屉上的路上不收，在抽屉里点过标题也照样离开即收）；抽屉只有这一种悬停浮出，没有固定打开（没有用得上的场景）。用鼠标点过钮之后，鼠标离开之前悬停不浮出（点了不会马上又浮出来；离开再移回来照常浮出），键盘按的不锁。悬停浮出是临时的，摆法一变（放得下与否、换了文件、切回编辑）即清掉。摆法由脚本按滚动区宽度定（量滚动区宽，纯函数算停靠的目录宽、放不下为 null），显示成什么由纯函数按「开着 / 放得下 / 悬停」定，工具栏钮、版心与抽屉都按它走，版心让位由 CSS 按目录宽算。抽屉用共用的 Popover（Base UI），只用它定位与点外面、Esc（收起浮出的），它报来的打开与点钮请求一律取消、不留痕迹；悬停不用它的（它打开有延迟，在抽屉里按过鼠标后移出也不收），由悬停状态（空闲 / 浮出中 / 锁住）自己处理：鼠标进出目录钮与抽屉各报一次，离开后等 100ms（跨过钮与抽屉间 4px 的间隙）才算离开，期间进了另一个即作罢；用鼠标点钮锁住，离开即解锁。抽屉浮出时不抢焦点，键盘收起时焦点回正文、鼠标收起时留在点下去的地方；开关同一颗 `PanelLeft`（title「目录」）、同一个按栏的开关状态（会话内保持、切换文件保持、默认开），只在预览态、文中有标题时出现。标题读渲染出的页面（同查找索引）：取带源码行的 `h1`–`h6`，所以原始 HTML 写的标题也算、GFM 脚注区生成的读屏标题不算；显示文字折叠空白，没有文字的（如只有一张图）不列。缩进按嵌套关系算：挂在前面最近一个级别更高的标题下，跳级的（`##` 下直接 `####`）只比上级深一层。点一行 = 按该标题的源码行滚到视口顶边（与阅读位置同一套换算，收起的 `<details>` 里的标题落到它所在的块）并把焦点还给正文；当前标题 = 起始行不在视口顶边所在行之后的最后一个（顶边在第一个标题之前时不点亮），点过的那一行在滚动位置变化之前一直点亮（文末几节滚不到视口顶边，按位置算会点亮前面的）；当前行以最小距离滚入目录的视口。正文重渲染（如另一栏改了内容）即重列标题。
- SVG 预览与位图共用同一个看图组件：尺寸角标、缩放与平移、四档与双击切轴、Cmd/Ctrl+0 与 +/-、方向键切媒体都与位图相同（规则见 `files-tab.md`「看图」「方向键切媒体」）；从位图切到 SVG 时自动进预览态。

## Testing Decisions

- 预览渲染本身（react-markdown / `<img>`）不配组件单测；相对图片路径的根内校验复用已有的路径解析（已有测试覆盖）。
- 扩展名判定（Markdown / SVG / 可切预览的源文件 / 看图可展示 / 相邻媒体）表驱动单测。
- 缩放几何（适配倍率、滚轮倍率、相机锚点、相机 → 瓦片视口映射）表驱动单测。
- 查找换算表驱动单测：匹配（大小写、全词含中文与非词字符两端、不开正则时正则符号按原字、不在词界上的候选不挡住重叠的下一个、emoji 等两个码元的字按整字跳过、正则的行首行尾 / 空命中跳过 / 写错报无效）、跨节点命中落到节点与偏移、块间不相连、代码块外的空白折叠与 CRLF、代码块里空白原样。
- 渲染链单测（与预览同一条插件链）：frontmatter 的键值表（标量照字面、空值留空、表标第 0 行且正文照常标行）、嵌套的表与不展开的别名、写错的 YAML / 重复的键 / 列表 / 纯文字原样成 YAML 代码块、空的与只有注释的不显示、值里的 HTML 当文字；块元素带起始行、行内元素不带，原始 HTML 的块（`details`、`summary`、`p`）同样标行；代码块的复制文本去掉末尾补的换行、缩进与空行原样（含空代码块与原始 HTML 的 `<pre>`）；脚本、事件属性、`style` 与 `javascript:` 链接被去掉；行内 / 块判定表驱动。行与位置的换算见 `files-tab.md` 的测试决策。
- 目录换算表驱动单测：缩进层数（逐级、同级、不从一级开始、跳级、回到更高的级别）、停靠的目录宽（宽裕、正文到最窄前后、两者都到最窄、放不下侧边）、目录的显示（开着且放得下在侧边，侧边显示着时悬停不另浮出，侧边没显示时悬停浮出抽屉、不悬停不显示）、悬停（侧边没显示时进来即浮出、离开即收，用鼠标点钮锁住、离开解锁，键盘按钮不锁）、当前标题（顶边在第一个标题之前、正好在标题行、两个标题之间、最后一节、没有标题）；渲染链单测覆盖标题标行、脚注区的读屏标题不标。
- 外部行为（切换与位置对齐、图片、链接、尺寸标注、选中复制、代码块复制钮、查找高亮与滚动、目录的跳转与跟随点亮、开关、随宽度让位、宽窄切换时侧边隐去与回来、悬停即时浮出、在抽屉里点标题后离开即收、点钮后不移出不浮出、移出再移回照常浮出）人工回归。

## Out of Scope

- 目录的折叠子标题与拖宽；编辑态的大纲。
- 编辑 / 预览边滚边跟的滚动同步（WebStorm 三态；Editor Tab 分栏的一栏编辑、一栏预览各自滚动）；两态切换那一刻的位置对齐不在此列。
- 代码块语法高亮。
- 相对链接跳转到项目内其他文件。
- Mermaid / KaTeX 等扩展渲染。
- TOML（`+++`）与 JSON 写的 frontmatter。
- HTML 等其它格式的预览（PDF 见 `files-pdf-preview.md`）。
- Markdown 正文里引用的 SVG 相对路径图（仍只放行位图扩展名）。
