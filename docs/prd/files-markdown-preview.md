# files-markdown-preview

**Files 编辑器 Markdown / SVG 预览**

## Problem Statement

在 Files Tab 里打开 README、文档等 Markdown 文件时只能看到源码，想确认渲染效果（表格、图片、层级）得切去别的工具，写文档的「所见」链路断了。打开 SVG 时同样只能看 XML 源码，无法立刻核对图形。

## Solution

Markdown 与 SVG 文件的工具栏出现「编辑 ↔ 预览」两态切换：编辑态还是原来的 CodeMirror。Markdown 预览态把正文换成排版后的富文本（GFM 语法、代码块、表格、相对路径图片），正文可选中复制，Cmd+F 在排版后的正文里查找并高亮（与编辑态共用一个查找栏，切换不关、不清空）；SVG 预览态把源码画成图形，并在内容区右上角显示像素宽高（与位图预览同一套角标）。默认进预览态（新建的空文件进编辑态），切换状态会话内保持。在编辑与预览之间切换时停在同一处内容：预览的每一块都记得自己来自源码第几行，两态按此对应；换到别的文档从头开始，切回来回到上次看的位置（规则见 `files-tab.md`「阅读位置」）。CSV / TSV 也用同一两态，预览是表格（见 `files-xlsx-preview.md`）。

## User Stories

1. As a 开发者, I want 打开 .md 文件时工具栏出现预览切换钮, so that 我能一键在源码与渲染结果间切换
2. As a 开发者, I want 预览渲染 GFM（表格 / 任务列表 / 删除线 / 自动链接）, so that GitHub 风格的文档所见即所得
3. As a 开发者, I want 预览里的相对路径图片正常显示, so that README 里的截图不是裂图
4. As a 开发者, I want 点击预览里的外部链接用系统浏览器打开, so that 应用内不会被导航走
5. As a 开发者, I want 切到预览前自动保存, so that 预览内容与磁盘一致
6. As a 开发者, I want 预览的配色排版随应用主题, so that 深色下不会出现刺眼的白底
7. As a 开发者, I want 非 Markdown / SVG / CSV 文件的工具栏没有该按钮, so that 界面不被无关控件污染
8. As a 开发者, I want 切换文件后预览态保持, so that 连续浏览多个文档不用反复点切换
9. As a 开发者, I want 文档里夹的 HTML（`<br>`、`<details>`、`<kbd>`、带宽度的 `<img>` 等）像在 GitHub 上一样排版、但脚本不被执行, so that README 看起来和 GitHub 上一致，打开陌生仓库的 md 也不会带来脚本注入
10. As a 开发者, I want 打开 .svg 文件时工具栏出现同样的预览切换钮, so that 我能在 XML 源码与图形之间切换
11. As a 开发者, I want SVG 预览不执行文件里的脚本, so that 打开陌生仓库的图标不会带来脚本注入
12. As a 开发者, I want SVG 预览内容区右上角显示像素宽高, so that 我能确认图标实际尺寸
13. As a 开发者, I want SVG 预览与位图共用缩放 / 滚轮或拖拽平移 / 方向键切图, so that 看图标和看 PNG 是同一套操作
14. As a 开发者, I want 能选中并复制 Markdown 预览里的文字, so that 能摘录文档内容
15. As a 开发者, I want 在 Markdown 预览里 Cmd+F 查找，命中标黄、当前命中标橙并滚过去, so that 不切回源码也能在文档里找东西，手感同 PDF / PPT
16. As a 开发者, I want 编辑与预览之间切换时查找栏不关、查询与选项都在, so that 同一个文件里找同一个词不用重输
17. As a 开发者, I want 在编辑与预览之间切换时停在同一处内容, so that 源码里改完切过去就看到这一段的效果，在预览里看到要改的地方切回去就在眼前
18. As a 开发者, I want 换到别的文档时预览从头开始、切回来回到上次看的位置, so that 来回对照几篇文档不用重新找

## Implementation Decisions

- Markdown 渲染用 `react-markdown` + `remark-gfm`。原始 HTML 接 `rehype-raw` 解析成元素，紧接 `rehype-sanitize` 按默认白名单（即 GitHub 的规则）净化：脚本、事件属性、`style`、非 http(s) / mailto 等协议的链接去掉，`id` / `name` 加 `user-content-` 前缀防 DOM 劫持；净化放在最后一个引入外来内容的步骤之后。解析与净化都保留源码位置，源码行标注排在净化之后。行内与块按 HTML 规范的 phrasing content 判定（`hast-util-phrasing`，只看标签名），源码行标注与查找分块共用这一个判定。HTML 写的 `<img>`、`<a>` 与 Markdown 语法的走同一套相对路径图片与链接拦截。
- 排版用 `@tailwindcss/typography` 的 prose 类，色板通过官方 `--tw-prose-*` 变量对齐工作区 token（随应用主题），代码块用 `--font-mono`。
- SVG 预览用 `<img>` + `data:image/svg+xml`（CSP 已放行 `data:`），不当 inline XML，脚本不执行；放大时按新尺寸重新栅格化矢量，任何倍率清晰。打开分流仍为 text。
- 两态（编辑 / 预览）而非 WebStorm 三态分屏；状态会话内保持、不落盘，默认预览、新建文件时切回编辑。Markdown、SVG 与 CSV 共用同一开关。
- 切换钮在 Files 工具栏右侧钮区最左，与「最近打开 / 在文件树中显示 / …」以既有 1×12px `--border-input` 竖线隔成单独一组（同「显示文件树」）。
- 相对路径图片：按当前文件目录解析、限制在根内，经既有 dc-media 协议流式读取（CSP `img-src` 放行 `dc-media:`）。越界或非图片扩展名不渲染。
- 链接一律拦截默认跳转：http/https/mailto 交 `shell.openExternal`（复用既有 IPC），锚点与相对链接不动作。
- 切到预览前 flush 保存（与「离开 Files Tab 即保存」同语义）。
- 选中：应用全局禁选，Markdown 预览的正文容器单独放开；容器可聚焦，点进正文后 Cmd+F / Esc 归本预览，PageUp / PageDown 原生滚动。
- 查找：查找会话跟着文件走（规则见 `files-tab.md`「编辑器内查找」）——编辑与预览共用一份（开着与否、查询、区分大小写 / 全词 / 正则），切换不关、不清空、不抢焦点；SVG 预览没有查找，查找栏先藏起、切回编辑原样出现。查找栏同编辑器（`FindBar`，含正则开关，坏正则红字提示），匹配规则与表格、PPT 共用（`lib/text-find`，正则标志同编辑器）；Cmd+F 打开、Esc 关闭复用预览的键盘外壳（不给缩放回调，缩放键不接）。找的是排版后的页面文字：正文按块（段落、标题、列表项、表格格子、代码块）分段，块内跨行内元素（粗体、链接、行内代码）可连着命中，块与块之间不相连；代码块外连续的空格、换行（源码折行、CRLF）按显示的一个空格找，代码块里空白原样。块间排版换行与只给读屏的隐藏文字（GFM 脚注区标题）不算。高亮同 PPT 走 CSS Custom Highlight（与 PPT 共用同一对命中 / 当前命中），不改页面；首个命中取每轮查找开始时（打开、改查询或选项、从编辑态切过来）视口顶边及之后的第一个；两态的命中不一一对应，切换后从新视图的视口顶边重新数（两态已按内容对齐，起点是同一处），上一个 / 下一个循环，当前命中滚到视口正中。同表格 / PPT，打开查找（或正文变了）时建一次文字索引，每次输入只在索引里匹配；正文渲染只随内容变，查找打字不会让整篇重新解析。
- 阅读位置（规则见 `files-tab.md`「阅读位置」）：预览与编辑器共用「视口顶边所在的源码行」。渲染时用一个 rehype 插件给每个块元素标上源码起始行（`data-line`，同 VS Code 的 Markdown 预览），预览以这些块为对应点分段换算：行落在两块之间按高度比例插值，不按源码顺序排的块（GFM 脚注区）跳过；块的位置随页面排版缓存，页面尺寸一变（图片加载、拖窗口）重算。预览按文件重挂，换文件从头开始；图片在视口上方后加载撑高页面时，由浏览器原生的滚动锚定保持眼前的内容不动。
- SVG 预览与位图共用同一个看图组件：尺寸角标、缩放与平移、四档与双击切轴、Cmd/Ctrl+0 与 +/-、方向键切媒体都与位图相同（规则见 `files-tab.md`「看图」「方向键切媒体」）；从位图切到 SVG 时自动进预览态。

## Testing Decisions

- 预览渲染本身（react-markdown / `<img>`）不配组件单测；相对图片路径的根内校验复用已有的路径解析（已有测试覆盖）。
- 扩展名判定（Markdown / SVG / 可切预览的源文件 / 看图可展示 / 相邻媒体）表驱动单测。
- 缩放几何（适配倍率、滚轮倍率、相机锚点、相机 → 瓦片视口映射）表驱动单测。
- 查找换算表驱动单测：匹配（大小写、全词含中文与非词字符两端、不开正则时正则符号按原字、不在词界上的候选不挡住重叠的下一个、emoji 等两个码元的字按整字跳过、正则的行首行尾 / 空命中跳过 / 写错报无效）、跨节点命中落到节点与偏移、块间不相连、代码块外的空白折叠与 CRLF、代码块里空白原样。
- 渲染链单测（与预览同一条插件链）：块元素带起始行、行内元素不带，原始 HTML 的块（`details`、`summary`、`p`）同样标行；脚本、事件属性、`style` 与 `javascript:` 链接被去掉；行内 / 块判定表驱动。行与位置的换算见 `files-tab.md` 的测试决策。
- 外部行为（切换与位置对齐、图片、链接、尺寸标注、选中复制、查找高亮与滚动）人工回归。

## Out of Scope

- 编辑 / 预览分屏与边滚边跟的滚动同步（WebStorm 三态）；两态切换那一刻的位置对齐不在此列。
- 代码块语法高亮。
- 相对链接跳转到项目内其他文件。
- Mermaid / KaTeX 等扩展渲染。
- HTML 等其它格式的预览（PDF 见 `files-pdf-preview.md`）。
- Markdown 正文里引用的 SVG 相对路径图（仍只放行位图扩展名）。

## Further Notes

若未来要三态分屏，两态的预览组件可直接复用，只动编辑器的布局层。
