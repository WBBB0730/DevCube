## Problem Statement

仓库和下载文件夹里的 PPT（方案汇报、作品集、教程）在 Files Tab 里只能看到「无法在此编辑此文件」占位，得跳去 PowerPoint / WPS / Keynote 才能看内容。PDF 预览已经做得顺手，PPT 却还是断的。

## Solution

打开 PPT 时在正文区内嵌预览，手感与 PDF 预览一致：所有页自上而下连续显示、打开即整页显示得下；左侧缩略图侧栏点格直达、翻页跟随点亮；工具栏页码输入与「1:1 / 适应高度 / 适应宽度 / 适应窗口」四档；Cmd/Ctrl+滚轮与触控板捏合按光标缩放；文字可选中复制；Cmd+F 查找并只标出命中的字；页内跳转与网址链接可点；幻灯片里的音视频可以播放。认 .pptx 以及同一格式的放映版（.ppsx）、模板（.potx）与带宏版本（.pptm / .ppsm / .potm，宏不执行）。渲染引擎用 pptx-renderer，工具栏、查找栏、快捷键与主题是 DevCube 自己的，操作外壳与 PDF 预览共用。

## User Stories

1. As a 开发者, I want 打开 .pptx 文件时在右侧看到幻灯片而不是占位, so that 看汇报和作品集不用跳出去
2. As a 开发者, I want 放映版、模板和带宏的 PPT 也能打开, so that 同一种格式的变体不因扩展名不同而看不了
3. As a 开发者, I want 带宏的 PPT 只显示不执行宏, so that 打开陌生文件也安全
4. As a 开发者, I want 打开时整页显示得下, so that 先看到一页全貌
5. As a 开发者, I want 所有页自上而下连续滚动, so that 像读 PDF 一样一路翻下去
6. As a 开发者, I want 形状、渐变、表格、图表、SmartArt、裁切的图片都按原样显示, so that 设计类的页面不缺内容
7. As a 开发者, I want 用 Cmd/Ctrl+滚轮或触控板捏合按光标缩放、手感与看图和 PDF 一致, so that 不用记三套操作
8. As a 开发者, I want 缩放时文字始终清晰, so that 放大看细节不发糊
9. As a 开发者, I want 工具栏看到当前页 / 总页数并能输入页码跳转, so that 能定位到具体页
10. As a 开发者, I want 在页码框里没改页码就回车时停在原地, so that 误按回车不会跳回第 1 页
11. As a 开发者, I want 工具栏有「1:1 / 适应高度 / 适应宽度 / 适应窗口」四档且互斥点亮, so that 既能指定看法，也看得出自己在哪一档
12. As a 开发者, I want 「1:1」按幻灯片原尺寸显示, so that 能核对版面的真实大小
13. As a 开发者, I want 拖窗口或显隐文件树之后所处的档位仍然贴合, so that 改完布局不用再点一次
14. As a 开发者, I want 空白处双击在「适应宽度 / 适应高度」之间切换、文字上双击仍是选词, so that 常用切换不必抬手去工具栏
15. As a 开发者, I want Cmd/Ctrl+0 回适应窗口、Cmd/Ctrl +/- 逐档缩放, so that 不碰滚轮也能调
16. As a 开发者, I want ↑/↓ 上一页 / 下一页、翻到头再按就切到上一个 / 下一个媒体文件，←/→ 直接切文件, so that 与 PDF 一样逐页看、跨文件翻
17. As a 开发者, I want 正文左侧看到每页缩略图、点格直达、翻到哪页点亮哪格, so that 能按版式找页
18. As a 开发者, I want 缩略图开关与 PDF 共用、切换文件后保持, so that 两种文档的侧栏习惯一致
19. As a 开发者, I want 能选中并复制幻灯片里的文字, so that 能摘录内容
20. As a 开发者, I want 在空白处或图片上拖动、或按住空格拖动就能抓着页面走, so that 放大后移动方便又不丢选字
21. As a 开发者, I want Cmd+F 打开与编辑器同款的查找栏，支持区分大小写与全词、上一个 / 下一个、计数, so that 能在长的演示文稿里找关键词
22. As a 开发者, I want 查找只把命中的那几个字标黄、当前命中标橙并滚到视口正中, so that 一眼看到位置，同 PDF 与编辑器
23. As a 开发者, I want 查找从当前页起找第一个命中, so that 不用每次从头翻
24. As a 开发者, I want 没显示出来的页里的文字也能被查到, so that 查找覆盖整份文档
25. As a 开发者, I want 目录页里「跳到某页」的按钮与文字可点, so that 能从目录直达章节
26. As a 开发者, I want 网址链接用系统浏览器打开, so that 应用内不被导航走
27. As a 开发者, I want 幻灯片里嵌的视频与音频能播放, so that 演示里的演示视频也能看
28. As a 开发者, I want 本机没装文档用的字体时仍保持原字体的风格（黑体类用黑体替补、宋体类用宋体替补、代码字体用等宽替补）, so that 不会整页变成带衬线的默认字体
29. As a 开发者, I want 「个 人 简 历」这种分散对齐的标题按原样拉开铺满一行, so that 设计类版面不走样
30. As a 开发者, I want 几十页、几十 MB 的演示文稿也能很快打开且滚动不卡, so that 大文件也敢直接点开
31. As a 开发者, I want 加密、损坏或异常巨大的文件给出明确提示并能「在其他应用中打开」, so that 不对着空白
32. As a 开发者, I want 深浅两套主题下页面保持原样、四周随主题, so that 不刺眼
33. As a 开发者, I want 在文件树里一眼认出 PPT 文件, so that 找文件时分得清类型
34. As a 开发者, I want 预览窗口（Preview Window）里打开 PPT 也是同样的预览, so that 双击文件打开时一样好用
35. As a 用户, I want 在设置「文件打开方式」里把 DevCube 设为 PPT 的默认打开程序, so that 在 Finder / 资源管理器里双击 PPT 就用它看
36. As a 用户, I want 安装后 DevCube 出现在 PPT 的「打开方式」列表里但不抢默认, so that 装了它不会打乱我原来的 PowerPoint / WPS / Keynote
37. As a 用户, I want 预览窗口的类型筛选里单独有一项「PPT」, so that 在混杂文件夹里只看演示文稿

## Implementation Decisions

- 分流：主进程按魔数识别 PresentationML 的六种 MIME（演示文稿 / 放映 / 模板，及三者的带宏版本）→ 打开类型 pptx，文件走既有 `dc-media` 协议 URL；渲染层一次取回交给库。只认内容 MIME，不单凭扩展名；老二进制 .ppt 仍占位。扩展名表（六种）与图片 / PDF / 音视频同一张「文件打开方式」表：打包时声明文件关联（角色 Viewer、优先级 Alternate，只进「打开方式」列表、不抢默认），设置「系统集成 → 文件打开方式」多一个「PPT」子项（Info hover 列六种扩展名，按钮「设置」，已是默认显示「默认」），预览窗口的树顶类型筛选多一项「PPT」；Linux 设默认用 freedesktop 登记的 MIME 原名。同一张表还用于文件树图标（讲台 `Presentation`，物件本身的图标）与方向键切换的媒体序列。
- 渲染引擎：pptx-renderer（Apache-2.0，纯 TypeScript，HTML / SVG 输出），ZIP 按库推荐的限额解压（条目数、单条目与总解压大小、媒体总量），媒体按需解码；选型与放弃 react-pptx 的理由见 ADR-0033。只用库的单页渲染，不用它自带的查看器（缩放即重建、自管滚动）。
- 页面列表：演示文稿只有一个页面尺寸，所以按等高行直接算位置——一行 = 页高 + 10px 页间留白（同 PDF），滚动容器不留内边距（「适应高度」按容器高算）；页窄于视口时水平居中，宽于视口时贴左并出横向滚动。只挂视口内及上下各一页；每页挂载时交库画一次，之后只随倍率改 CSS 缩放（库先按原尺寸排好一页再整体缩放），卸载时释放该页的图表等资源；同一文档各页共用媒体对象 URL，关文档时统一回收。
- 缩放与四档：四档一一对应「原尺寸 / 宽度铺满 / 高度铺满 / 两轴取小」，倍率夹在 0.1–25（同 PDF.js 的上下限）。换倍率的取整也同 PDF.js：Cmd/Ctrl +/- 每档乘 1.1 后按 0.1 取整（放大向上、缩小向下，落在整齐倍率上），滚轮与捏合的新倍率按 0.01 取整。换倍率时让锚点下的内容留在原处：纵向按「第几页 + 页内比例」换算（页间留白不缩放），横向按页内比例；锚点——滚轮 / 捏合取光标，Cmd/Ctrl +/- 取视口中心，双击取双击点，点四档钮与尺寸变化取视口左上角。连续滚轮在一帧内多次换倍率时以最近一次请求的倍率与待落的滚动位置为基准。容器尺寸变化（拖窗口 / 文件树与缩略图显隐 / 查找栏开合）时所处的档按新尺寸重算，自由倍率不动，尺寸塌成 0（Tab 切走）时一概不动。双击：「适应窗口」先判它实际顶住的是哪条轴再切到另一条，「1:1」与自由倍率落适应宽度。
- 当前页：原来的页仍整页可见就不变，否则取视口里露出比例最大的一页（并列取靠前的），同 PDF.js——末尾几页一屏装下时 ↓ 仍能逐页前进。跳页同 PDF.js：目标页顶对齐视口顶，这页横向没完整露出（放大后）时横向回到页左缘、完整露出则不动。
- 操作外壳与 PDF 共用：全局键盘（Cmd+F、Cmd/Ctrl+0 / + / -、←/→ 切文件、↑/↓ 翻页到头切文件、Esc 关查找，让路规则同 PDF）、拖拽抓手与按住空格抓手、空白处双击（mousedown 的 `detail === 2`）、Cmd/Ctrl+滚轮与捏合（倍率常量复用看图）、工具栏页码与四档、缩略图开关、打不开时的占位，都从 PDF 预览抽成共用件，PDF 行为不变。页码框没改就回车只失焦（原先会落到第 1 页，一并修正）。
- 抓手让路：文字（直接含非空白文字的元素）、链接与按钮、音视频控件、以及指针显示为手指的元素（库给图形上的链接以行内样式设了 pointer，没有别的标记）上的鼠标动作让给点击与选字；按住空格时处处抓手。文字上是 text 光标，抓手模式下处处 grab。
- 缩略图侧栏：与 PDF 共用同一个侧栏（固定宽、虚拟列表、三态格子、点格跳页并把焦点还给正文、翻页跟随），格子内容由调用方给——PPT 是缩小画的整页（随格子挂载即画、不排队），PDF 仍是渲染器缓存的小图（取页顺序的纯逻辑与侧栏几何抽成共用）。开关状态与 PDF 共用、会话内保持。
- 查找：文字索引一份文档在打开查找时建一次，每次输入只在索引里搜（区分大小写 / 全词，无正则开关，同 PDF）；首个命中取「打开查找 / 改查询时的当前页」及之后的第一个；上一个 / 下一个循环。高亮用浏览器的 CSS Custom Highlight（不改页面内容），全部命中黄、当前命中橙（同 PDF 的两种色），各预览往同一个命名高亮里增删自己的区间。命中落到页面文字：库的文字按段落以换行相连、页面上段落间不占字符，扣掉命中前的换行即页面文字偏移；元素、表格格子与项目符号靠补丁贴的标记定位（元素标记 = 层:编号，层取母版 / 版式 / 本页，编号只在层内唯一），倒影副本与项目符号不计；页面文字与库的文字对不上（如公式）时不标。当前命中每次滚到视口正中，所在页没挂载时先滚到它的页顶。
- 链接：文字里的网址由库生成 `<a target=_blank>`，走 Chromium 开窗请求 → 主进程开窗守卫 → 系统浏览器（同 PDF）；跳页链接与图形上的链接经库的导航回调回来，跳页走同一个跳页、网址交主进程 openExternal（与 IPC 同一份 http/https/mailto 白名单）。
- 字体与分散对齐：库原先只给几个已知中文黑体补备选字体，其余缺失字体落到浏览器默认的衬线字。改为缺字体时按原字体风格补同风格的备选：西文风格看西文位字体（等宽 / 无衬线 / 衬线，按名字里的关键字与一张常见西文衬线字体短表判断），中文风格从后往前取第一个看得出中文风格的字体（名字里的宋 / 明 / 楷 / 仿宋与对应拼写为衬线，黑 / Gothic / Sans 与库的已知黑体为无衬线，其余中文名字默认无衬线），都看不出则随西文；两者一致时直接补中文备选（常见的微软雅黑等与原先完全一样），不一致时先补西文通用字体再补中文备选——浏览器逐字取字，西文字母落在前者、汉字跳过它落在后者。分散对齐改为连最后一行也铺满（并声明按字符间距分配，内核升级到支持后对西文自动生效）。两处都以 pnpm 补丁修在库上，见 ADR-0033。
- 主题：容器 `--bg-deepest`，页面保持原样白底并带与 PDF 相同的阴影。
- CSP：`media-src` 放行 `blob:`（幻灯片内音视频的对象 URL），理由同缩略图放行 `img-src blob:`。库的嵌入字体以字节构造 FontFace，不经网络、不涉及 CSP。

## Testing Decisions

- 分流：六种 PresentationML MIME → pptx、老 ppt 的 MIME 不认（`files-kind.test.ts`）；PPT 扩展名判定与方向键媒体序列包含 PPT（同上）；文件树图标（`files-tree-icon.test.ts`）；预览窗口类型筛选归「PPT」、老 ppt 归「其他」（`files-type-filter.test.ts`）。「文件打开方式」各平台的注册与设默认是逐类遍历同一张表的既有逻辑（既有测试覆盖），新增一类不另配单测；注册效果装打包版人工验证，macOS 设默认可用 Dev 小壳先验。
- 页面列表几何、四档倍率、按锚点缩放后的滚动位置（含锚点落在页间留白）、可见页范围、当前页判定（含末尾几页一屏装下）、查找结果的层:编号标记、查找命中到页面文字的换算（跨文字节点、段落换行不占字符、节点边界取法、不换行空格、对不上不标）表驱动单测（`files-pptx.test.ts`）。
- 缩略图取页顺序的纯逻辑随抽出挪到共用模块，原测试原样保留（`files-page-thumbnails.test.ts`）。
- 补丁后的字体回退规则在打补丁时按典型组合（单独微软雅黑、思源黑体、西文 Arial + 中文宋体、西文位宋体 + 中文位微软雅黑、Times + 思源黑体、Cambria + 微软雅黑、Consolas、Monotype Corsiva、带复杂文种位的组合、阿里巴巴普惠体、Noto Serif SC）逐条核对过；库是第三方代码，不在本仓库配单测。
- 渲染、链接、音视频是库与浏览器行为，不配组件单测；用真实样本（设计类简历、28 页 30 MB 教程、可编辑版对照原图）人工回归：打开 / 四档与双击 / 滚轮与捏合锚点 / Cmd+0 +/- / 改窗口大小后是否贴合 / 翻页与缩略图跟随 / 查找标字与居中 / 跳页与网址链接 / 字体风格与分散对齐 / 切走项目再回来 / 损坏文件。

## Out of Scope

- 老二进制 .ppt（没有可靠的纯前端渲染，不借外部软件）。
- 动画、切换效果、放映模式；演讲者备注与批注。
- 编辑、导出、打印。
- 「EMF 里内嵌 PDF」的矢量插图（常见于 Mac 版 PowerPoint 粘贴的矢量图）：库要在后台线程加载 PDF.js，生产态渲染层是 `file://`，这一轮不接，这类插图不显示（见 ADR-0033）。
- 外部修改后自动刷新（与图片 / PDF 同，尚无此机制）。

## Further Notes

- 选型的实测对比与放弃 react-pptx 的理由见 ADR-0033；补丁内容见仓库的 pnpm 补丁文件，升级库版本时须重做或随上游修复删除。
- 同期评估过 Word（docx）预览：可用的纯前端库会丢形状与文本框，设计类文档缺内容，暂不做。udoc-viewer 不作候选：引擎闭源、不许打补丁，免费版每次打开都要联网验证。
