# 服务器文件管理

## Problem Statement

我经常要改服务器上的配置、看日志、把本机打好的包传上去。现在要么在 **SSH Terminal** 里用 vim、cat 凑合，要么另开 WinSCP 或 FinalShell 的文件面板。DevCube 已经能连服务器、看状态，项目里的 **Files Tab** 也能浏览、预览和编辑文件，唯独服务器上的文件还得出门处理。

## Solution

每台 **Server** 恒有一个 **Files Tab**，常驻它的 Tab 栏第二位（紧接 **Status Tab**），不可关闭。它复用项目 **Files Tab** 的整套面板（左正文、右文件树），只是树里是服务器上的文件：

- **一栏**：树从服务器的 `/` 开始，第一次打开时自动展开到家目录；树顶输入路径可直接前往。本机那边交给 Finder，不做 WinSCP 式的左右双栏。
- **打开即编辑、手动保存**：文本直接编辑，点「保存」或按 ⌘S 才写回服务器（不自动保存：改到一半的配置不该生效，多人同时改时也不该频繁打断）；编辑器上方一条保存栏显示状态，会丢修改前先问。图片、PDF、PPT、Excel、音视频先下载到本机再用现有预览。
- **上传下载**：从 Finder 拖到树上即上传，右键也能上传、下载；底部传输栏显示进度，可取消。
- **基础文件管理**：新建、重命名、删除。服务器上没有回收站，删除不可恢复。
- **点「连接」才连**：和 **Status Tab** 一样，不会一点开就连上、弹出密码框。
- **经内置连接**（ADR-0041）：配置照你的 ssh 配置，走服务器的 SFTP，终端连得上，文件就连得上；服务器上什么都不用装。

## User Stories

1. 作为用户，我想点开一台 **Server** 后在「状态」之后看到「文件」Tab，尚未连接时显示「尚未连接到 X」和「连接」按钮。
2. 作为用户，我想连上后看到从 `/` 开始的文件树，第一次打开时自动展开到我的家目录并滚到那里，以便从常用位置开始，又能展开到 `/etc`、`/var/log` 等任何目录。
3. 作为用户，我想在树顶输入一个路径（绝对路径或 `~` 开头）回车就前往：是目录则展开并定位，是文件则打开，以便不用一级级点开。
4. 作为用户，我想展开没有权限的目录时看到「没有权限」，而不是一片空白。
5. 作为用户，我想点开服务器上的文本文件直接编辑，改完点「保存」或按 ⌘S 才写回服务器，以便改配置不用在终端里用 vim，改到一半的内容也不会先生效。
6. 作为用户，我想打开服务器上的图片、PDF、PPT、Excel、音视频时，看到下载进度、可以取消，下载完直接预览。
7. 作为用户，我想打开较大的文件时先看到占位说明，而不是一点开就干等：文本超过 5 MB、其余可预览的文件超过 10 MB；占位里有「下载」和「在 SSH 终端中打开」，除文本与 Excel 外还有「仍然打开」，以便偶尔真要看大 PDF 或视频时点一下就开始下载。
8. 作为用户，我想把文件或文件夹从 Finder 拖到树上某个目录就上传到那里（拖到文件行即上传到它所在的目录），也能右键「上传文件…」「上传文件夹…」。
9. 作为用户，我想右键「下载…」把文件或文件夹下载到本机我选的位置（默认「下载」文件夹）。
10. 作为用户，我想在面板底部看到进行中的上传、下载的进度，能取消，全部完成后自动收起；失败的留下原因。
11. 作为用户，上传或下载遇到同名时，我想选择「替换」或「跳过」，并可勾选「对其余同名项同样处理」。
12. 作为用户，我想在树上右键新建文件、新建文件夹、重命名，规则与项目的 **Files Tab** 一致。
13. 作为用户，我想删除前看到确认框写明「删除后无法恢复」，因为服务器上没有回收站。
14. 作为用户，我想右键「在 SSH 终端中打开」，在这台 **Server** 下新开一个 **SSH Terminal**，登录后就在那个目录。
15. 作为用户，我想右键「复制路径」拿到服务器上的绝对路径。
16. 作为用户，我在 **SSH Terminal** 里改了文件，切回文件 Tab 时想看到树和打开的文件已经更新；我还想要一个刷新按钮随时手动刷新。
17. 作为用户，保存时或切回来时发现服务器上的文件已经被别人改过，我想在保存栏里选「重新载入」或「覆盖保存」，而不是悄悄覆盖掉别人的修改，也不被弹框打断输入。
18. 作为用户，我想切到别的 Tab 或别的条目时连接不断、传输不停；也想随时手动断开。
19. 作为用户，连接意外断开时，我想看到原因和「重新连接」，编辑器里还没保存的内容不丢，重连后再保存。
20. 作为用户，需要密码时，我想照常在 SSH 提问弹窗里回答；记住的密码自动填上。
21. 作为用户，重启 DevCube 后我想文件 Tab 回到未连接状态、不自动连接，连上后恢复上次展开的目录、打开的文件和最近打开列表。
22. 作为用户，编辑服务器的连接信息或移除服务器时，它的文件连接随之断开；移除时一并忘掉它的展开状态与最近打开。
23. 作为用户，我想在编辑器上方的保存栏里一眼看到有没有未保存的修改、是否正在保存、保存是否失败，并能「放弃修改」回到服务器上的版本。
24. 作为用户，有未保存的修改时，切换到别的文件、断开连接、改服务器的连接信息或移除服务器、关闭窗口或退出 DevCube 之前，我想先被问一句，以免修改丢失；切到别的 Tab 或条目、只改服务器的名称或密码时不问，修改会留着。
25. 作为用户，再次打开刚看过、服务器上也没变的文件时，我想直接看到内容而不再等下载；服务器上的文件变了则照常重新下载，不拿到旧内容。

## Implementation Decisions

- **Tab**：键为 `files:server:<id>`（`files:<条目键>`，与项目的 `files:<项目路径>` 同一前缀，Cmd+W 无效）。**Server** 的常驻 Tab 按序为 Status、Files，⌘2 直达；默认激活规则不变（有运行中的 **Run Session** 先激活它，否则落在 **Status Tab**）。未连接 / 已断开的样式与文案同 **Status Tab**。
- **连接与协议**：每台服务器至多一条文件连接，由主进程管理，独立于 **SSH Terminal** 与状态连接（不复用 ssh 连接）；服务器上的配置选工作目录时的「选择服务器上的目录」对话框也用这一条（打开即连接，关掉不断开，见 `docs/prd/ssh-server.md`）。经内置连接（ADR-0041，`docs/prd/ssh-connection.md`）自己连一条（连接目标、绕开代理直连，ADR-0039；保活同状态连接），在上面开两个 SFTP 通道（ssh2 的 SFTP）：浏览（列目录、查信息、新建、重命名、删除、读写文本、打开时的下载）与传输（上传 / 下载队列），上传下载进行时浏览与打开照常；通道出错或被关后，下次使用时重开。读写在 ssh2 的基本读写之上按块并发（每块 32 KB），同时在途的块数按往返时延自适应（快线路跑满带宽，慢线路上服务器那边只排着一两块），取消即停止发新请求；不用 ssh2 自带的 fastGet / fastPut（固定 64 块在途、中途停不下来）。服务器没有启用 SFTP 子系统时，显示明确的原因。不限 Linux。
- **面板宿主**：`FilesPane` 新增 `server` 宿主（与 `project` / `preview` 并列），宿主差异仍集中在 `host` 上；读写经「文件后端」（本机走 `files:*`，服务器走 `server-files:*`），面板的读写流程不区分宿主。正文里是否本机文件由一个上下文告诉工具栏与各预览，据此去掉本机专属入口。远程路径一律按 POSIX 处理，本机是 Windows 时也不经 Node 的平台 `path`。
- **根与导航**：根恒为 `/`。首次打开时展开从 `/` 到家目录的每一级并滚到家目录（家目录由 SFTP 的 realpath `.` 取得）。树顶栏左侧的筛选框换成路径输入框（占位「前往路径…」），接受绝对路径和 `~` 开头的路径；⌥⌘F 聚焦它；焦点在树上打字同项目转进它；切走 Tab 时清空输入与出错提示。⌥⌘F、⌘E 只认面板挂上之后按的：没连上时按的、断开前按过的，连上后不补。树顶栏右侧去掉「全部展开」（从 `/` 递归展开等于遍历整台服务器），加「刷新」（进行中显示转圈图标、按钮置灰，结束后转到原位才换回刷新图标并恢复）；「断开连接」放在树顶固定的当前文件夹行右端。展开状态、上次打开的文件、最近打开按条目键 `server:<id>` 持久化（ADR-0002）；恢复时不预先检查路径（要连上才查得了），上次打开的文件已不在时，原因显示在工具栏，并清掉记住的打开文件；打开失败且服务器上已不在的，从最近打开里去掉（本地的在启动时剔除，服务器上要连上才查得了）。
- **树**：隐藏规则、排序同项目。符号链接按目标类型显示，指向目录的可展开；断链按文件显示，打开时报错。读目录失败（如无权限）时在该目录的子级位置显示一行原因，收起再展开会重读（本地同样适用）。
- **打开**：先按扩展名分流，否则读服务器上文件的开头若干字节嗅探类型，规则同本地。按服务器上的大小判断是否下载：文本上限 5 MB（与本地编辑器的上限一致），其余可预览类型 10 MB（Excel 与本地预览的上限一致）；超过则显示占位（「下载」「在 SSH 终端中打开」），不下载。文本与 Excel 的上限是编辑器与表格预览本身的上限，没有「仍然打开」；其余类型的占位另有「仍然打开」，点了照常下载预览。上限固定，不做成设置：快慢取决于每台服务器的带宽，一个全局数字对哪台都不准。文本直接读进编辑器；其余下载到本机缓存目录后走现有预览（`dc-media` 协议放行该目录，ADR-0010 / ADR-0032），点开后超过 150 ms 还没打开，正文区盖住旧文件：还没开始下载（查大小、判断类型）时为「正在加载…」，开始下载后为下载进度与「取消」；盖上之后换打开别的文件也一直盖着，旧文件不会在两次打开之间露出来；同一版本上一次判断过类型的不再读开头（占位上点「仍然打开」即直接开始下载）；取消即时生效：已发出的读请求不等回来，关闭文件的回复也不等（服务器按序回复，它排在未回来的读请求之后）；图片与 PDF / PPT 预览按文件重挂，遮罩撤掉时不露出上一份。同一台服务器同一时刻只打开一个，新的打开取消旧的。方向键切上一个 / 下一个媒体同本地：还在下载时从正在打开的那个往下数（连按即连跳），超过上限的媒体占位上照样能切；不预取相邻的图（要额外下载）。打开过的文件留作副本，见下条。
- **副本**：打开过的文件留一份副本，记下当时服务器上的修改时间（秒）与大小；再打开时先查这两项，都对得上就直接用副本（不再嗅探类型、不再下载），对不上即作废、重新下载。SFTP v3 只给得出这两项，没有内容指纹（OpenSSH 的 sftp-server 也没有取哈希的扩展），同一秒内改动且大小不变、或用保留修改时间的方式（如 `rsync -t`、`cp -p`）换成同样大小同样时间的内容，认不出来；这与保存前查冲突、刷新时的判断是同一口径，要绝对最新只能每次重读。为少拿旧内容：自己的保存、新建、重命名、删除、上传直接作废对应副本，不靠核对；下载完再查一次，下载期间变了（或期间有自己的改动）的只用这一次、不留。预览类副本在磁盘上（本机缓存目录，每份一个目录，超大图片切出的瓦片也放在里面，随副本一起删），所有服务器合计 2 GB，与本机的瓦片缓存一致；文本副本只放内存（最可能含密钥，不写磁盘），合计 50 MB；超出按最久没打开的淘汰，正在显示的除外。上限固定、不做成设置：副本只在连接期间存在，平时用不满；设成 0 也挡不住预览本身要先下载到本机。不跨重启：服务器上的内容不该在没人用时留在本机（包括进到备份里），跨重启复用的好处又小。手动断开、改了服务器的连接信息或移除服务器时丢弃，退出与启动时整个清空；意外断开时保留（面板里的预览还在用，连回来后打开照样先核对）。
- **保存**：手动保存，不做自动保存（本地仍是事件自动保存）：服务器上的配置改到一半就写回会先生效，多人同时编辑时频繁写入也更容易撞车。点保存栏的「保存」或按 ⌘S（编辑态与预览态都可，有弹层时让位）写回；原地覆盖写入（保住权限、属主和符号链接），同本地。写前取服务器上的修改时间（秒）与大小，与载入时比对，变了就不写、转为冲突。保存期间又键入的内容不算已保存。切到 Markdown / SVG / CSV 的预览不先保存，预览显示编辑器里的内容。SFTP 没有文件锁，拦不住别人同时改，只能在保存时与切回来刷新时发现。
- **保存栏**：服务器上的文本文件才有，常驻在面包屑工具栏之下、编辑器之上（常驻免得编辑器上下跳）。状态依次为：冲突（「服务器上的文件已被修改……」+「重新载入」「覆盖保存」；已被删除时为「服务器上的文件已被删除……」+「放弃修改」「保存」，保存即重新创建；不弹框）、正在保存、连接已断开（重新连接后才能保存）、保存失败（原因 +「重试」）、有未保存的修改（「放弃修改」「保存」）、已保存。「放弃修改」即重新读服务器上的版本。保存出错写在这里，不再写在面包屑工具栏上。
- **会丢修改前先问**：有未保存的修改时，切换到别的文件、断开连接、改这台服务器的连接信息（`serverConnectionChanged`：连接目标、是否直连；只改名、改密码、改地址大小写不算）或移除它之前弹「保存 / 不保存 / 取消」（「不保存」在底栏左侧）；存不上（冲突或出错）就不继续。正在编辑的文件再点一次不重读。改名跟着改路径，编辑留在编辑器里。退出 DevCube 时并进退出确认（渲染端把未保存的文件数报给主进程）；macOS 与 Linux 关主窗口即销毁渲染端，也先确认（Windows 关窗只是隐藏到托盘）。切到别的 Tab 或条目不问。
- **刷新**：不定时轮询。切回文件 Tab、窗口回到前台、断线后连回来时各刷新一次：只重读已展开的目录与根，其余缓存丢掉、再展开时现读；打开的文件先比对修改时间与大小，变了才处理：文本重读（沿用本地的 noop / reload / conflict / gone 判定，本地也改为修改时间与大小一起比），预览与占位重新打开；有未保存的修改时，文件被删除或长过文本上限都转为保存栏里的冲突，不关、不重开（手动保存，修改可能放了很久）；正在打开别的文件时不动。展开目录时现读；自己的操作与上传完成后立即刷新。意外断开期间不刷新（读失败会被当成目录已删、把树收起）。
- **文件操作**：新建、重命名（就地改名，重名即失败）、删除（文件夹连同内容逐项删除），命名校验与打开文件的联动同项目（`docs/prd/files-tree-management.md`）。删除确认框写明「删除后无法恢复」。不做复制、移动、改权限、改属主。
- **上传**：拖放用 Electron `webUtils.getPathForFile` 取本机路径；落在目录行即该目录，落在文件行即其所在目录，落在空白处不接受；拖动时高亮目标目录。右键「上传文件…」「上传文件夹…」分成两项（Windows / Linux 的系统对话框不能同时选文件和文件夹）。文件夹递归上传。
- **下载**：右键「下载…」，单个文件弹保存对话框，文件夹选目标目录后在其中建同名文件夹；默认位置为系统「下载」文件夹。不做从树拖到 Finder（开始拖时文件必须已在本机）。
- **同名处理**：上传、文件夹下载时逐个询问「替换 / 跳过」，附「对其余同名项同样处理」；单个文件下载的同名由系统保存对话框处理。
- **传输栏**：Files Tab 底部，列出进行中的上传、下载（名称、进度），可逐个取消，全部完成后自动收起，失败的保留原因直到关掉；选完文件时连接已断开的也照样列进来，以失败收口。传输不随切 Tab 暂停。手动断开、改了服务器的连接信息或移除服务器时中止进行中的传输；有传输进行中时，手动断开与退出 DevCube 都先确认。
- **右键菜单**：树上为新建文件、新建文件夹、上传文件…、上传文件夹…、下载…、在 SSH 终端中打开、复制路径、重命名、删除；去掉在文件夹中显示、在其他应用中打开、在终端中打开、复制相对路径、复制文件 / 复制文件夹。正文右键保留「复制图片」，其余本机专属项换成「下载…」。工具栏保留面包屑、最近打开、在文件树中显示，去掉本机专属的两个按钮。
- **在 SSH 终端中打开**：在这台 **Server** 下新开一个 **SSH Terminal**，登录后进入该目录（文件则进入所在目录）；断线后按回车重连仍进入该目录；目录不随壳持久化，重启后回到登录目录，同 **Terminal**。
- **连接生命周期**：点「连接」才建立；切走不断；手动断开前有未保存的修改先问（见上）；意外断开时面板保留，顶部显示原因与「重新连接」，树菜单、「刷新」与「前往路径」停用，点文件、展开没读过的目录不做事，⌘S 不保存，「仍然打开」「下载」停用，编辑器内容保留，连回来后再保存；手动断开再连上是重新挂载面板，文件树显隐、编辑 / 预览态与撤销记录回到默认；编辑服务器时连接信息（连接目标、是否直连）变了、或移除服务器即断开（只改名、改记住的密码、改地址大小写不断开），移除时删除它的持久化状态；DevCube 退出时一并结束。
- **不提供**：树顶筛选（依赖本机文件索引）、**Content Search**、Git 改动标记、在其他应用中打开（预览出错的占位改给「下载」）、Markdown 预览里相对路径的图片（要逐张下载）。

## Testing Decisions

沿用项目约定：只测纯函数，零 mock。

- 远程路径：规范化（只认 `/`，文件名可含 `\`）、`~` 展开、「前往路径」输入的接受与拒绝；根为 `/`（及 `C:/`）时的子路径拼接与取父目录。
- 打开分流：按类型与服务器上的大小判定「直接读 / 下载 / 占位」，以及占位是否带「仍然打开」（5 MB、10 MB 边界）。
- 刷新：打开的文本相对一次重读的 noop / reload / conflict / gone，修改时间与大小都比。
- 副本：版本对得上才复用、对不上即作废；分服务器；下载期间有自己的改动、或本身超过上限的不收；同一路径新版本替换旧版本；超出上限按最久没用淘汰、跳过正在显示的；正在显示的被作废时换下来再丢；作废文件夹连同其下一切、不误伤同名前缀；丢掉某台服务器的全部连同正在显示的。
- 树：读不出来的目录在子级位置出提示行。
- 上传落点：目录行、文件行。
- 同名处理：「对其余同名项同样处理」的批量决策。
- 常驻 Tab：**Server** 的 Tab 序（Status、Files）与默认激活。
- 连接失败说明（没启用 SFTP）；「在 SSH 终端中打开」的远端命令。
- 退出确认：有未完成的传输时的文案。
- SFTP 共用部分：状态码的中文说明；条目类型；读写分块计划（顺序出块、短读补读、读到文件尾即止）；在途窗口（起步 1 块、不排队时加、排队多了减、上下限、基准取最短往返）。

落在 `src/shared/server-files.test.ts`、`src/shared/sftp.test.ts`、`src/shared/files-path.test.ts`、`src/shared/files-watch.test.ts`、`src/shared/files-tree-flatten.test.ts`、`src/shared/tab-activation.test.ts`、`src/shared/server.test.ts`、`src/shared/quit-guard.test.ts`、`src/main/server-files-copies.test.ts` 与 `src/main/command.test.ts`。不写 UI / e2e 测试。

实测记录：

- 已实测（macOS 15.7、本机 OpenSSH 9.9；服务器 Ubuntu、OpenSSH 9.6，香港云服务器，往服务器上传约 5 MB/s，服务器出口约 2 Mbps）：`ssh -s … sftp` 上手写的最小 SFTP v3 客户端，按每块 32 KB、最多 64 个未完成请求，上传 100 MB 为 5.13 MB/s、下载 10 MB 为 0.35 MB/s；同一条连接上纯 ssh 通道为 4.97 / 0.24 MB/s，系统 `sftp` 命令为 4.55 / 0.26 MB/s，均已跑满带宽，下载文件校验一致。握手 78 ms；列 `/etc`（217 项）245 ms、`/usr/bin`（1120 项）约 2 秒（受服务器出口带宽限制），展开大目录需要「加载中」。服务器公布的扩展含 posix-rename、home-directory、limits 等。
- 已实测（macOS 15.7，本机 `/usr/libexec/sftp-server` 直接接在客户端上，临时测试、验证后删除）：握手、列目录（普通文件 / 目录 / 符号链接）、跟随符号链接 stat、UTF-8 文本读写、读开头、5 MB 流水线读（进度）与流水线写、文件比 stat 时短、新建（已存在即失败）、改名、删除、状态码的中文原因、传输中途取消后连接照常可用、连接断开后请求一律失败。
- 已实测（本机 `/usr/libexec/sftp-server`，中间接一段模拟线路：限带宽、单程 20 ms，临时测试、验证后删除）：固定 64 块在途时，256 KB/s 下载期间与取消后查一次信息都要约 8 秒；改为按时延自适应后，5 MB/s、256 KB/s、30 KB/s 三档吞吐为 4.2 MB/s、245 KB/s、29 KB/s，下载中 / 取消后查一次信息为 62 / 61 ms、214 / 251 ms、1.3 / 2.1 秒；取消后 50 ms 内返回，连接照常可用。
- 待实测：经 DevCube 界面连真实服务器的整体效果（连接、浏览、打开与手动保存、副本复用与服务器上改动后重新下载、未保存提示、冲突、上传下载与同名询问、意外断开与重连）。
- 待实测：Windows 上系统 OpenSSH 以管道方式启动（与状态连接相同的问题）。

## Out of Scope

- WinSCP 式本机 / 服务器左右双栏。
- 复制、移动（含树内拖拽移动）、改权限、改属主、属性面板。
- 多选与批量操作。
- 从树拖到 Finder 下载；在本机其他应用中打开服务器上的文件。
- 定时自动刷新；实时跟随增长中的日志（用 **SSH Terminal** 里的 `tail -f`）；大文件只看末尾。
- 树顶筛选、**Content Search**、Git 改动标记。
- 以 sudo 身份编辑无权限的文件。
- 目录同步、断点续传、服务器之间直接传输。
- 常用目录收藏、跟随 **SSH Terminal** 当前目录。
- 与 **SSH Terminal**、状态连接共用一条连接（ssh 的连接复用）。
- 服务器上的压缩与解压。
- 专门适配 Windows 服务器的路径形式。
