# files-tree-move-copy

**Files 文件树：移动、复制与多选**

## Problem Statement

**Files Tab** 的文件树只能新建、重命名、删除。要把文件挪到别的文件夹、复制一份、把 Finder 里的文件放进项目，或把项目里的文件拖给别的应用，都得切去 Finder 或 **Terminal**。树也只能一次操作一个条目，没有键盘操作，整理一批文件要一个个右键。

## Solution

文件树有自己的选中（可多选），支持：

1. **拖拽**：树内拖动即移动，按住 ⌥（Windows / Linux 为 Ctrl）即复制；从 Finder / 资源管理器拖进来即复制进项目；从树拖出到 Finder、桌面或聊天窗口即带出文件本身。
2. **剪切 / 复制 / 粘贴**：右键菜单与 ⌘X / ⌘C / ⌘V，与系统剪贴板互通——树里复制的能粘到 Finder，Finder 里复制的能粘进树。
3. **多选**：⌘ 点选、⇧ 连选，拖动、删除、剪切、复制、压缩、复制路径都能一次处理多项。
4. **键盘**：焦点在树上时方向键移动选中、收起展开，Enter 打开，F2 重命名，⌘⌫（Windows / Linux 为 Delete）删除，⌘A 全选。

**Server** 的 **Files Tab** 只加树内拖动移动、多选与键盘操作；没有复制与剪贴板，不能拖出（Finder 拖入仍是上传）。**Preview Window** 与项目的 Files Tab 相同。

## User Stories

1. As a 开发者, I want 把文件拖到另一个文件夹上就移过去, so that 整理目录不用切 Finder
2. As a 开发者, I want 拖动时按住 ⌥ 就是复制, so that 手感同 Finder
3. As a 开发者, I want 拖到折叠的文件夹上停一下它就展开, so that 能一路拖到深层目录
4. As a 开发者, I want 拖到树的上下边缘时自动滚动, so that 长树里也能拖到看不见的位置
5. As a 开发者, I want 把 Finder 里的文件拖进树就复制进项目, so that 不用先去 Finder 找项目目录
6. As a 开发者, I want 把树里的文件拖到 Finder、桌面或聊天窗口, so that 发文件、备份不用先找到它在磁盘上的位置
7. As a 开发者, I want 在树上 ⌘C 后到 Finder 里 ⌘V 得到一份拷贝, so that 和系统剪贴板互通
8. As a 开发者, I want 在 Finder 里复制文件后到树上 ⌘V 粘进来, so that 两边双向都通
9. As a 开发者, I want 剪切再粘贴就是移动, so that 键盘也能挪文件
10. As a 开发者, I want 在同一个文件夹里粘贴时自动改名避开, so that 能快速复制一份副本
11. As a 开发者, I want 移到的地方有同名条目时问我替换还是跳过、并能对其余同名项一次决定, so that 不会悄悄覆盖
12. As a 开发者, I want ⌘ 点选、⇧ 连选多个条目, so that 一次拖动、删除或复制一批
13. As a 开发者, I want 单击文件就在正文看到内容、焦点仍留在树上，双击才进到文件里, so that 点一下就能看，又能接着用键盘挑文件、用快捷键，想改时双击直接打字
14. As a 开发者, I want 在没选中的条目上右键时选中换成它, so that 菜单作用的永远是高亮的那些
15. As a 开发者, I want 被收起或被筛掉的条目不再算选中, so that 删除、移动不会碰到看不见的东西
16. As a 开发者, I want 一次删除多项时只确认一次, so that 不用连点
17. As a 开发者, I want 用方向键在树上移动、收起展开, so that 不碰鼠标也能浏览
18. As a 开发者, I want 按 F2 重命名、按 ⌘⌫ 删除, so that 常用操作不用开菜单
19. As a 开发者, I want 移动当前打开的文件（或它的上层文件夹）后编辑器不断开, so that 正文、面包屑与最近列表都指向新位置
20. As a 开发者, I want 服务器上也能拖动移动文件, so that 整理服务器目录不用开 **SSH Terminal**

## Implementation Decisions

- **选中**：独立于正文打开的文件，可多选，另有一个焦点行（最近点选或键盘停留的行，⇧ 连选从它起算）。单击只看：文件 = 选中并在正文显示内容，焦点留在树上（接着用键盘与快捷键）；文件夹 = 只选中。双击进去：文件 = 打开并把焦点交给正文（文本进编辑器，直接可键入），同 Enter；文件夹 = 展开或收起（同左树：连续点击中第 2、4、6… 下各切换一次），点展开箭头也只开合、不改选中。⌘（Windows / Linux 为 Ctrl）点选切换单项、⇧ 点选连选，都不打开。从 **Git Tab**、最近打开、**Content Search**、前往路径、「在文件树中显示」打开文件时，选中换成该文件。树上只有一种高亮（`--selection-row`），打开的文件不另标。选中只含看得见的行：父文件夹被收起、被筛选掉即移出选中。选中不落盘，切走 Tab 再回来保留。
- **右键**：点在已选中的行上，菜单作用于全部选中；点在没选中的行上，选中换成这一行；点在空白区清空选中、作用于根。多选时菜单只有剪切、复制、粘贴、压缩、复制路径（一行一个）、删除；新建、重命名、在文件夹中显示、在其他应用中打开、在终端中打开、复制相对路径不出现。
- **菜单排布**：新建 → 打开 → 剪切 / 复制 / 粘贴 → 压缩 / 复制路径 / 复制相对路径 → 重命名 / 删除。原「复制文件 / 复制文件夹」并入「复制」。正文右键菜单不变。
- **键盘**（同 WebStorm 的树；焦点在树上时，打字转进树顶输入照旧）：↑ / ↓ 移动焦点行并选中（文件即打开，同单击），⇧↑ / ⇧↓ 扩选；→ 在收起的文件夹上展开，其余同 ↓；← 在展开的文件夹上收起，其余跳到所在文件夹（只选中，不打开）；Enter 在文件上同双击（打开并把焦点交给正文），在文件夹上展开或收起；F2 重命名（单选时）；⌘⌫（Windows / Linux 为 Delete）删除；⌘A 全选看得见的行；⌘X / ⌘C / ⌘V 剪切 / 复制 / 粘贴。⌘X / ⌘C / ⌘V 在树的键盘处理里接下并拦住，不再交给应用菜单的编辑项（页面没有选中文字时，浏览器的复制粘贴命令在非输入区不会触发）。
- **方向键归属**：只看焦点——焦点在树上全归树，焦点在正文照旧（切媒体、PDF / PPT 翻页）。点一下正文、或在文件上按 Enter，焦点即进正文；**Preview Window** 打开时焦点默认在正文。
- **剪贴板**：复制与剪切都把所选条目放进系统剪贴板（通道同现有「复制文件」，见 `files-tab.md`），剪切另记下「待移动」的那一批，被剪切的行淡显；这一批由主进程统一记，主窗口剪切、在预览窗口里粘贴也认，变了推给所有窗口。粘贴读系统剪贴板里的文件：仍是刚剪切的那一批即移动（读过即撤掉剪切，之后再粘贴就是复制），否则复制进来（含 Finder 里复制的文件）。别处复制了东西没人通知：粘贴时、以及有剪切时窗口回到前台，向主进程核对一次，剪贴板已被换掉即撤掉剪切、取消淡显。剪切后粘到 Finder 里按 Finder 自己的规则（拷贝）。粘贴的目标：右键处，否则焦点行；文件行即其所在文件夹；都没有时为根。
- **拖拽落点**：文件夹行即它，文件行即其所在文件夹，空白处即根（服务器上空白处仍不接受，同上传）。拖动中目标文件夹高亮（同上传）；悬停在收起的文件夹上约 600 ms 自动展开；靠近树的上下边缘自动滚动。不能落到被拖条目自身、它的子文件夹或它原本所在的文件夹。拖已选中的行带上全部选中，拖没选中的行只拖它自己（选中不变）。
- **拖拽机制**：本机的树开始拖动时一律交给系统原生文件拖拽（Electron `webContents.startDrag`），同一次拖动既能落回树内，也能拖出到 Finder 等应用；落回树内时以真实来源为准：都在这棵树的根内即移动（⌥ 为复制），否则复制进来（同 Finder 判同一磁盘）；拖动中还拿不到来源路径，落点能不能放、显示移动还是复制按「这次是不是从本树拖出的」判断。系统原生拖拽只许复制 / 链接时（Windows 上 Electron 的 startDrag 即如此），移动也只能显示为复制。左树与 Tab 栏用的 dnd-kit 接不住系统文件，这里不用。服务器的树没有本机文件可交，树内拖动走页面内拖放。取舍见 ADR-0057。
- **同名**：跨文件夹遇到同名，逐个问「替换 / 跳过」，附「对其余同名项同样处理」（同服务器上传）。替换时原有条目本机进回收站，WSL 项目与服务器上直接删除，确认文案写明不可恢复。同名的文件夹整个替换，不合并。复制到它原本所在的文件夹（原处粘贴、⌥ 拖回原处）时自动编号避开，格式同全应用统一的编号（「 (2)」「 (3)」……）。
- **批量**：同时选中文件夹和它里面的条目时，去掉被包含的那些（同压缩的规则）。删除多项时只确认一次（「删除 N 项？」）。逐项执行，某项失败时已完成的保留、停在失败项报错。压缩一次压全部所选（压缩窗口本就支持多项，见 `compress.md`）。
- **联动**：移动沿用重命名的联动——先落未保存的编辑，打开的文件、展开集、选中、最近打开按路径前缀重映射，再从磁盘刷新树。打开的文件被替换掉时同删除的联动。
- **主进程**：新增移动、复制两条 Files IPC，目标一律走根内越界校验；外部拖入或粘贴来的来源只读、不要求在根内。复制文件夹递归；不跟随符号链接，复制链接本身。服务器上的移动是 SFTP 跨目录改名，打开的文件未保存的编辑跟着改路径（同服务器上的重命名）。
- **服务器**：树内拖动移动、多选、键盘操作同本机；菜单与键盘里没有剪切 / 复制 / 粘贴，按住 ⌥ 拖动不接受放下；多选时「下载…」选一个目标文件夹，所选各项下载进去（规则同文件夹下载）。

## Testing Decisions

- 纯逻辑表驱动单测：选中（单击、⌘ 切换、⇧ 从焦点行连选、键盘移动与扩选、→ / ← 在收起 / 展开的文件夹与文件上的去向、收起或筛选后移出看不见的行、从别处打开时换成该文件）；拖拽落点（文件夹 / 文件 / 空白、服务器空白处不接受、自身 / 子文件夹 / 原处不接受）；多选去掉被包含的条目；原处复制的编号；粘贴判定（剪贴板里是否仍是剪切的那一批）。
- 移动后的路径前缀重映射沿用既有测试。
- 主进程移动 / 复制的落盘逻辑（同名、递归、符号链接、越界）用临时目录测。
- 系统剪贴板读写多个文件、拖出到其他应用、拖入、回收站依赖 Electron 与系统，三平台人工回归。

## Out of Scope

- 服务器上的复制与粘贴（SFTP 没有复制命令）。
- 从服务器的树拖到 Finder 下载；本机项目的树与服务器的树之间互相拖。
- 撤销移动、复制与删除。
- 内联重命名（仍走弹窗）。
- 同名文件夹合并。
- 复制进度显示。
- 拖到 **Terminal** 里插入路径。

## Further Notes

- 待实测：`startDrag` 固定的拖放效果（electron/electron#15361）下，拖回树内时光标能否区分移动与复制；macOS 上多个文件写入与读取系统剪贴板的通道（现有「复制文件」只放一个 `public.file-url`）；Windows 上读剪贴板里的文件列表；部分 Linux 发行版拖入时拿不到文件列表（electron/electron#41977）。
- 文件树的键列在设置快捷键列表的「文件树」组（`settings-keymap.md`）。
