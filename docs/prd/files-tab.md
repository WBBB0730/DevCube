# files-tab

**Files Tab**

## Problem Statement

我在 DevCube 里跑项目、看 Git，改一行配置或源码却还要切到 WebStorm / 系统编辑器。Git 变更树里的「打开文件」也只丢给系统默认应用，和面板内的工作流是断的。我需要在不离开 DevCube 的前提下，浏览项目里的文件并直接编辑。

## Solution

每个 **Project** 的 Tab 栏增加常驻、不可关闭的 **Files Tab**（标签：图标 +「文件」），排在 **Git Tab** 之后、会话 Tab 之前：

1. **左正文 + 右文件树**：树展示项目根下条目；**不按 `.gitignore` 过滤**（仍可见 `node_modules` 等），但隐藏 WebStorm「Ignored Files and Folders」默认项（如 `.git`、`.DS_Store`）；同一时刻至多打开一个条目。
2. **树顶过滤**：树顶常驻筛选框，按相对路径包含匹配收窄**同一棵树**（保留结构，不另开结果面板）；基于文件名索引，跳过 IDE 忽略名 + gitignore（见 ADR-0009 / ADR-0027）。
3. **按类型分流**：文本用 CodeMirror 6 编辑（仅语法高亮与文本编辑，无 lint / 补全 / 跳转；不上外部 LSP）；图片、PDF、PPT、Excel、Chromium 可播的音视频内嵌预览，方向键按可见树序切上一个 / 下一个媒体；CSV / TSV 仍进编辑器，可切成表格预览；SQLite 文件（按文件头识别）内嵌 **Data Source Tab** 的视图，见 `docs/prd/database.md`「SQLite」；其余只读占位，并可「在其他应用中打开」。PDF / PPT / Excel 的细节见 `files-pdf-preview.md` / `files-pptx-preview.md` / `files-xlsx-preview.md`。
4. **事件自动保存**（对齐 WebStorm 体感）：换文件 / 离开 Files Tab / 失焦或短空闲时写入；无显式脏标记弹窗常态。
5. **与 Git 打通**：Git 里「打开文件」进入该项目 Files Tab 并打开对应路径；Files Tab 保留「在其他应用中打开」。
6. **左栏不动**：ProjectTree 仍只做项目 / 配置；文件树仅出现在 Files Tab 内。新建 / 重命名 / 删除见 `files-tree-management.md`；复制 / 移动不做（仍走系统文件管理器或 **Terminal**）。

## User Stories

1. 作为开发者，我想项目 Tab 栏里常驻一个 **Files Tab**（「文件」），以便不用找入口就能浏览项目文件。
2. 作为开发者，我不想关掉 Files Tab，以便它和 **Git Tab** 一样始终在。
3. 作为开发者，我想 Files Tab 排在 Git 之后、运行会话与终端之前，以便两个常驻工具面挨在一起。
4. 作为开发者，我想用 `Ctrl+Tab` / `Ctrl+Shift+Tab` 也能循环到 Files Tab，以便键盘在全部 Tab 间移动。
5. 作为开发者，我想在 Files Tab 上按 `Cmd/Ctrl+W` 无效，以便不会误关常驻 Tab。
6. 作为开发者，我想看到含 `node_modules` 等 gitignore 条目的完整文件树、但不看 `.git` / `.DS_Store` 等 IDE 默认忽略项，以便不漏文件又和 WebStorm Project 树一致。
7. 作为开发者，我想展开 / 折叠目录浏览树，以便逐级找到文件。
8. 作为开发者，我想点击文件就在右侧打开它，以便立刻查看或编辑。
9. 作为开发者，我想树里的文件图标和文件类型对应（图片、PDF、PPT、音频、视频、文本、代码、JSON、表格、脚本、压缩包），以便扫一眼就分得清。
10. 作为开发者，我想同一时刻只打开一个条目，以便界面保持轻量、没有内层文件 Tab。
11. 作为开发者，我想换文件时自动保存当前缓冲，以便不丢键入、也不被弹窗打断。
12. 作为开发者，我想用 CodeMirror 6 编辑文本文件，以便有语法高亮和基本编辑体验。
13. 作为开发者，我想文本只有语法高亮与基本编辑，不要补全、悬停、跳转或诊断，以免单文件无工程上下文时误导。
14. 作为开发者，我不想接外部 LSP / 语言服务器，以便 Files Tab 不膨胀成迷你 IDE。
15. 作为开发者，我想打开图片时在右侧内嵌预览、看到像素宽高，能缩放、平移，并用方向键切上一个 / 下一个媒体，以便不用跳出去看资源。
16. 作为开发者，我想打开可播的音视频时在右侧内嵌预览（播放/暂停/进度），以便不用跳出去听或看。
17. 作为开发者，我想打开播不了的音视频（如 mkv）时直接看到占位，而不是先尝试播放再失败。
18. 作为开发者，我想打开无法在此编辑的二进制时看到占位说明，以便知道为什么不能改。
19. 作为开发者，我想在 Files Tab 里一键「在其他应用中打开」当前条目，以便预览不够时交给系统应用。
20. 作为开发者，我想在图片上右键「复制图片」直接粘到聊天或文档里，在任何正文或树条目上右键「复制文件 / 复制文件夹」粘到访达 / 资源管理器即为拷贝，以便拿文件不用先去文件夹里找。
21. 作为开发者，我想点面包屑中的某一段就在文件树里定位到它，以便从路径快速找到树节点。
22. 作为开发者，我想一键「在文件树中显示」当前打开的文件，以便树滚偏后仍能回到该文件行。
23. 作为开发者，我想从「最近打开文件」菜单点回最近打开过的文件，以便快速回到刚改过的文件。
24. 作为开发者，我想从 Git 里「打开文件」直接进 Files Tab 打开该路径，以便 Git 与编辑不断档。
25. 作为开发者，我想未打开任何条目时提示「在右侧选择文件」，以便知道下一步点哪里。
26. 作为开发者，我想文本自动保存，以便接近 WebStorm 的保存体感。
27. 作为开发者，我想没有未落盘改动时，被外部改过的文件静默重载，以便跟得上 Terminal / 其他编辑器的改动。
28. 作为开发者，我想在「还有未落盘改动且磁盘也变了」时被提示选择重载或保留编辑器内容，以便不静默丢键入。
29. 作为开发者，我想在 Finder / Terminal / 其他工具里增删改文件后，已展开的文件树自动跟上，以便不用折叠再展开或重启。
30. 作为开发者，我想当前打开的文件被外部删除时静默回到空态，以便不对着幽灵路径。
31. 作为开发者，我不想在 Files Tab 里复制 / 移动文件（新建 / 重命名 / 删除见 `files-tree-management.md`），以便这类操作仍走 Finder 或 Terminal、保持轻量。
32. 作为开发者，我想左栏仍然只显示项目和运行配置，以便运行器主路径不被文件树占据。
33. 作为开发者，我想重启后恢复该项目上次打开的路径、树展开状态与最近打开列表，以便接着改同一个文件。
34. 作为开发者，我想上次路径已不存在时静默回到空态，以便不弹恼人错误。
35. 作为开发者，我想首次进入项目时有运行中的 Run Session 就进第一个运行中的、否则落到 Git Tab，以便闲置看 Git、有活进程看输出。
36. 作为开发者，我想关闭某个会话 Tab 时仍落到左邻（其次右邻），以便关 Tab 手感不跳去别的运行中会话。
37. 作为开发者，我想切走 Files Tab 再切回来时编辑现场（未保存的缓冲与滚动位置）还在，以便和 Git / xterm 一致。
38. 作为开发者，我想保存失败时得到明确反馈，以便知道磁盘权限或路径问题。
39. 作为开发者，我想在文件树顶用筛选框按路径收窄树，以便大项目里不用逐级点开找文件。
40. 作为开发者，我想过滤仍显示为树（命中项及其祖先），而不是另开扁平结果列表，以便保持目录上下文。
41. 作为开发者，我想过滤按相对路径包含、不区分大小写匹配，以便输入短片段就能命中。
42. 作为开发者，我想目录路径命中时显示该目录下全部子项，以便盯住整支目录。
43. 作为开发者，我想过滤时自动展开到所有命中，以便一眼看到目标文件行。
44. 作为开发者，我想清空过滤后恢复原来的展开状态、并仍能看到当前打开的文件，以便临时望远镜不影响原来的浏览位置。
45. 作为开发者，我想焦点在文件树上时直接打字即写入过滤、Esc 清空，以便不用先点输入框。
46. 作为开发者，我不想过滤文字跨 Tab / 重启被记住，以免树「缺了一截」造成困惑。
47. 作为开发者，我想过滤期间「全部展开 / 全部折叠」只作用于过滤后的树，以便在命中子集里继续收放。
48. 作为开发者，我想无匹配时看到「无匹配文件」提示，以便知道不是树坏了。
49. 作为开发者，我想过滤跳过 IDE 忽略项与 gitignore 条目，以便不被 `node_modules` 等拖慢、刷噪声（树里仍可手动展开它们）。
50. 作为开发者，我想过滤开着时外部文件变更也会刷新过滤结果，以便望远镜视图不落后于磁盘。
51. 作为开发者，我不想一期做快速打开（Cmd+P），以便过滤只解决「按路径收窄树」（内容搜索见 `content-search.md`）。
52. 作为开发者，我想在焦点在别处时用 Alt+CmdOrCtrl+F 切到 Files Tab 并聚焦文件树筛选框（文件树隐藏时先展开），以便不用先点树再输入。
53. 作为开发者，我想用 CmdOrCtrl+2 直达 Files Tab（与 Git 的 CmdOrCtrl+1、栏内第 3–9 位对称），以便和浏览器式 Tab 直达一致。
54. 作为开发者，我想不管项目多大，过滤都在秒级内出结果，以便超大仓库里筛选也可用。
55. 作为开发者，我想首次过滤建索引期间看到「正在扫描」提示，以便不把空白误当无结果。
56. 作为开发者，我想过滤命中成千上万个文件时树依然流畅滚动，以便宽泛查询下也能翻结果而不是页面卡死。
57. 作为开发者，我想在编辑器里用 Cmd/Ctrl+F 打开 WebStorm 式的顶部查找栏，以便文件内定位不再面对样式突兀的默认面板。
58. 作为开发者，我想打开 PDF 时在右侧内嵌预览（翻页、缩略图、缩放、选字、查找），以便看设计稿和文档不用跳出去（细节见 `files-pdf-preview.md`）。
59. 作为开发者，我想打开 PPT 时在右侧内嵌预览，操作与 PDF 一致，以便看汇报和作品集不用跳出去（细节见 `files-pptx-preview.md`）。
60. 作为开发者，我想打开 Excel 时在右侧看到只读表格、CSV / TSV 能切成表格预览，缩放与查找的操作与 PDF / PPT 一致，以便看数据不用跳出去（细节见 `files-xlsx-preview.md`）。
61. 作为开发者，我想在焦点在别处时用 CmdOrCtrl+E 弹出「最近打开文件」、上一个文件已预选、纯键盘选中后直接接着键入，以便不碰鼠标回到刚改过的文件（对齐 JetBrains Recent Files）。
62. 作为开发者，我想文件树最上面固定一行项目根文件夹名、右键它即根菜单，以便文件铺满树区时也能对根目录新建、在终端中打开等（同 Preview Window）。

## Implementation Decisions

- **Tab 模型**（ADR-0005）：每项目常驻非会话 Tab，恒排第二（Git → Files → 会话）、不可关闭，Cmd+W 无效。默认激活：有运行中的 Run Session 取第一个，否则按 Tab 序（即 Git Tab）；关闭会话 Tab 仍回落左邻、其次右邻。
- **布局**：Files Tab 内左正文、右文件树；左栏 ProjectTree 不改。空态文案「在右侧选择文件」。工具栏：可点面包屑（点段 → 树展开并滚到对应行）+「最近打开文件」（最多 10 条，按项目持久化，空列表时提示暂无）/「在文件树中显示」/「在文件夹中显示」/「在其他应用中打开」。文件树顶栏：左侧常驻筛选框（占位与 title 同文案）+ 右侧「全部展开」/「全部折叠」/「隐藏文件树」；其下、列表之上固定一行当前文件夹（项目根文件夹名，hover 全路径，右键即空白区那份根菜单），与 Preview Window 同一实现。
- **文件树**：文件行图标按扩展名归大类（共享纯函数 `filesTreeIconKind`，只看名字不读盘），一律用物件本身的 lucide 图标、不用「文件 + 角标」一系；PDF 为自绘「圆角方框 + Acrobat 风格卷纹」（lucide 无），未知二进制用通用文件图标。**展示不读 `.gitignore`**；隐藏名对齐 WebStorm「Editor → File Types → Ignored Files and Folders」默认掩码（`.git`、`.DS_Store`、`*.pyc`、`*~` 等；完整表见共享过滤模块）。目录按需读取；树行虚拟滚动、只渲染视口内的行（过滤命中再多也不卡）；展开状态按项目持久化。展开后读不出来的目录（如没有权限）在它的子级位置出一行原因，收起再展开会重读；打开失败的原因留在空态工具栏。
- **IPC 与路径安全**：主进程提供目录列举、读文件、写文件与系统打开，只放行授权根之内的路径（ADR-0032，防目录穿越）；另推送文件变更。渲染层 Files 状态按项目分桶，切走隐藏不卸载。
- **树顶过滤**（ADR-0009 / ADR-0027）：主进程用 ripgrep `--files` 一次枚举全项目建文件名索引（跳过 IDE 忽略名 + gitignore，非仓库只跳 IDE 名），按项目缓存、随文件监听作废，按键只做内存匹配，结果保留树结构；名单只含文件，名字命中的空目录不出现。输入防抖、以最新查询为准；冷索引首查的「正在扫描」延迟出现防闪烁，扫描完成前不显示「无匹配文件」。框里按 Esc 后焦点交给文件树；过滤期间的展开 / 折叠只改过滤视图，不写入持久化展开态。全局 Alt+CmdOrCtrl+F：有当前项目时激活其 Files Tab、必要时展开文件树、聚焦筛选框并选中已有查询（与左栏项目筛选 Alt+CmdOrCtrl+P 对称；不占用 CmdOrCtrl+F）。title / placeholder 里的快捷键文案按平台生成，走共享 `formatShortcutLabel`（ADR-0013）。
- **最近打开文件快捷键**：全局 CmdOrCtrl+E（主进程拦截，ADR-0013），Preview Window 同样可用；Windows / Linux 上焦点在终端（xterm）时 Ctrl+E 让给 shell。有当前项目时激活其 Files Tab，待面板首次恢复完成后打开「最近打开文件」下拉（Files Tab 被切走即收起）：预选第一个不是当前文件的条目（回车即回到上一个文件；点按钮打开不预选），↑ / ↓ 选择、回车或空格确认、Esc 关闭；选中条目、或 Esc 关掉 ⌘E 打开的下拉后，焦点进正文（文本进编辑器），点按钮打开的仍按常规还给按钮。菜单（含右键菜单）开着时，正文的全局方向键（切媒体 / 翻页）让位。按钮 title 带快捷键。
- **Base UI 补丁**：Base UI 1.0.0-rc.0 把非点击打开的菜单一律当悬停打开处理，受控打开后鼠标移入再移出即关；用 pnpm 补丁对齐上游 `@base-ui/react`——只有悬停打开的弹层才随鼠标离开关闭（全部 Base UI 菜单同此）。升级 Base UI 时补丁对不上安装即失败，须重做或在新版已修复时删除。
- **编辑器**：CodeMirror 6（`@uiw/react-codemirror` + 语言包高亮），关闭补全与 lint，明确不引入外部 LSP；查找等纯编辑器能力可用。
- **编辑器内查找**（Cmd/Ctrl+F，焦点在编辑器时）：编辑器顶部整宽查找栏（压下正文，对齐 WebStorm）替换 CodeMirror 默认搜索面板；匹配引擎复用 @codemirror/search 的 SearchQuery，高亮 / 计数 / 回绕导航自持（默认面板的高亮与其面板生命周期绑死，无法复用）；大小写 / 全词 / 正则、计数封顶 999+、坏正则红字提示；不做替换；默认查找键位（跳行 / 选下一个等）随默认面板一起移除。
- **语言高亮**（编辑器、内容搜索结果行与搜索预览三处共用同一映射）：官方 Lezer 包优先；官方无包的走 `@codemirror/legacy-modes` 词法级高亮（C#、Kotlin、Swift、Ruby、Lua、Shell、TOML、Dockerfile 等约 40 组长尾）；常见配置按近似语言高亮（如 .plist→xml、Unity .meta→yaml、.gitignore 族→properties）。legacy-modes 不带扩展名映射表，映射表自维护、按需逐文件引入。两边都没有语法的（zig / elixir / graphql / terraform 等）仍为纯文本。
- **保存**：事件自动保存——至少覆盖：切换打开条目、离开 Files Tab、窗口/面板失焦、短空闲。无常态「保存/不保存/取消」三按钮；竞态（未落盘 + 磁盘变更）单独弹窗：重载 / 保留编辑器内容。
- **外部变更**（ADR-0011 / ADR-0021）：主进程用 @parcel/watcher 原生递归监听，与 Git / discovery 共用每项目一条订阅，防抖后推送（从首个事件起最长 2s 必发）；只跳过 IDE 默认忽略名路径段，不硬编码 `node_modules` 等生态目录；Git 写动作期间该仓库的通知挂起、转闲后补发（不丢）。渲染端只重拉**已缓存**的目录列表（未展开过的不扫），过滤态重跑当前过滤；当前打开文本的修改时间与大小都没变则不动，否则无脏静默重载、有脏弹冲突、路径已删则静默空态并剔除最近打开。不用定时轮询。
- **持久化**：每项目记住上次打开路径 + 树展开状态 + 最近打开（最多 10，新→旧），走既有集中配置存储（ADR-0002）。路径无效 → 静默空态（树展开仍尽量恢复）/ 从最近列表剔除，不弹错。打开缓冲本身不要求跨重启持久（靠自动保存落盘）。
- **Git 集成**：Git 文件行「打开文件」（菜单与双击，已删除 / 未跟踪目录除外）改为聚焦该项目 Files Tab 并打开路径；系统打开改由 Files Tab（及二进制占位）上的「在其他应用中打开」承担。提交面板 / 详情菜单文案与行为对齐此分流。
- **打开分流**：已知文本扩展名走编辑器；其余用 `file-type` + `@file-type/av` 读魔数得 MIME。位图 → 看图（见下条）；svg 仍走文本，可切图形预览，看图操作同位图（见 `files-markdown-preview.md`）；PDF → PDF.js 官方 viewer 组件（`files-pdf-preview.md` / ADR-0030）；PPT（PresentationML 六种 MIME）→ pptx-renderer 单页渲染、DevCube 自排页面列表，外壳与 PDF 共用（`files-pptx-preview.md` / ADR-0033）；Excel（SpreadsheetML 四种 MIME，及 CFB 容器且文件名为 .xls）→ react-xlsx 只读表格，超过 10 MB 占位（`files-xlsx-preview.md` / ADR-0034）；Chromium 可播音视频 → 原生 `<audio>` / `<video>`；SQLite（`application/x-sqlite3`，本机的 Files Tab 与 Preview Window）→ 内嵌 **Data Source Tab** 的视图，连一个不登记的临时数据源（见 `docs/prd/database.md`「Files Tab」）；不可播音视频（如 mkv/wmv）与其它二进制 → 占位 +「在其他应用中打开」。魔数失败时：位图扩展名仍走图片；否则文本嗅探或占位。图片、音视频与 PDF / PPT / Excel 都经 `dc-media://` 特权协议读取、不经 IPC 传整文件，音视频显式响应 Range（206）流式播放（ADR-0010）。
- **看图**（位图与 SVG 预览态共用；四档、双击、Cmd/Ctrl+0 与 +/- 与 PDF 同一套，交互细则见 DESIGN.md）：内容区右上角显示像素尺寸（位图由主进程读文件头得宽高，EXIF 转 90° 的按显示方向报）。Cmd/Ctrl+滚轮按光标缩放（鼠标一格约 10%，触控板捏合跟手指距离；相对「适配视口且不放大」约 10%–3200%），+/- 按视口中心逐档（步长 1.1，同 PDF）。打开与换图时装得下视口的落 1:1、装不下的落适应窗口。双击在两条轴之间切换：从适应窗口进来时先按图与视口的宽高比判它实际顶住哪条轴、再切到另一条，1:1 与自由倍率落适应宽度；双击按 mousedown 的 `detail === 2` 判定，不接 `dblclick`（拖拽期间的全屏遮罩会接走 mouseup，dblclick 落不到预览区）。视口尺寸为 0（Tab 切走）时档位一概不重算。渲染分两档（ADR-0029）：像素数 ≤ 3200 万且单边 ≤ 16384 走浏览器原生 `<img>`（缩放停手 100ms 后按新尺寸重新栅格化，任何倍率清晰，GIF / 动态 WebP 照常播放）；超过的先出缩小解码的预览图（亚秒），后台生成瓦片金字塔后叠 OpenSeadragon 瓦片层，手感不变。换图时新图 120ms 内就绪直接替换、旧图不闪，超时撤下旧图（连同尺寸标注）显示「正在加载…」；切走即取消过期的加载与解码；相邻的图提前解码或备好预览与金字塔。浏览器解不了的图（如 Photoshop 写入超大 XMP 元数据块的 PNG）改走超大位图那条主进程出图的路并在本会话记住，仍失败则显示「无法预览此图片」占位（「重试」/「在其他应用中打开」）。
- **方向键切媒体**：序列 = 位图 / SVG / PDF / PPT / Chromium 可播的音视频，按树里当前可见的顺序（跨目录、只进已展开的目录；Preview Window 里还受类型筛选约束），到头停下、不回绕；Excel / CSV 不在序列里（方向键归表格移动选中格）。看图与音视频四个方向键都切（← / ↑ 上一个，→ / ↓ 下一个），音视频即使焦点在播放器上也拦下（播放器自己的键盘进度 / 音量让位）；PDF 与 PPT ←/→ 直接切，↑/↓ 翻页、在首页 / 末页再按也切。不抢输入框与弹层。
- **正文右键菜单**（任何已打开的条目）：复制图片（仅看图 / SVG 预览态）/ 复制文件 / 在文件夹中显示 / 在其他应用中打开；树菜单的「复制信息」组同样加「复制文件 / 复制文件夹」。复制文件由主进程把文件本身放进系统剪贴板，各平台走官方通道——macOS `public.file-url`、Linux `text/uri-list`；Windows 的 CF_HDROP 是预定义格式、writeBuffer 注册不了，交给系统自带 PowerShell 5.1 的 `Set-Clipboard -LiteralPath`（pwsh 7 已去掉该参数，须点名 powershell.exe）。复制图片在渲染层用 canvas 把图栅格化成 PNG 写系统剪贴板（主进程 nativeImage 只认 PNG / JPEG，这样渲染层能显示的都能复制；`dc-media` 带 CORS 头，canvas 不被污染）；复制的是屏上正显示的那张——超大位图与改由主进程出图的复制其预览图，加载中或打不开时不出「复制图片」。

## Testing Decisions

好测试：只测外部可观察的纯函数 / 契约行为，不测 CodeMirror 挂载与像素布局。先例：`runnable` / `project-sort` / git 解析类 vitest「构造输入 → 断言输出」。

- **路径安全**：归一化后必须落在根内；拒绝 `..` 穿越与根外绝对路径。
- **树忽略名**：是否按 IDE 默认 Ignored Files 隐藏（正例 `.git` / `.DS_Store`、反例 `node_modules` / `.env`）。
- **树顶过滤**：扁平相对路径名单 + 查询 → 过滤树与应展开路径（路径包含匹配、目录命中带整支子树、祖先构建、目录在前）。
- **树行拍平**：目录映射 + 展开集合 → 可见行（根子级恒可见、未展开不出子级、深度逐级递增、视觉序）。
- **打开分流**：扩展名 / MIME → 打开类型，表驱动；方向键媒体序列（按可见顺序跨目录、只进已展开的目录、含 PPT）；看图分档阈值、`.dzi` 解析、相机 → 瓦片视口映射。
- **默认激活**：Tab 列表 + 各会话是否运行中 → 期望激活键；关闭邻接用例与默认激活分离。
- **持久化形状**：缺省字段、无效路径清空当前打开、展开集读写。不测过滤文字持久化（明确不持久）。
- **外部变更**：目录列表是否等价（避免无变化重渲染）；打开文本相对磁盘读结果 → 不动 / 重载 / 冲突 / 已删（表驱动）。
- **应用快捷键匹配**：按平台与终端焦点表驱动——⌘E / Ctrl+E 命中、⌃ 不冒充 ⌘、Win / Super 不冒充 Ctrl、Windows / Linux 焦点在终端时 Ctrl+E 让位而 Ctrl+W / Ctrl+T 照常。
- **监听路径分类**：项目内路径进 Files；IDE 忽略名段、嵌套仓库下项目外路径不进；不测真实订阅。

不写 CodeMirror / e2e UI 测试。

## Out of Scope

- 快速打开（Cmd+P）/ 命中高亮（内容搜索见 `content-search.md`）
- 「排除目录」UI 或用户可配的第二套搜索排除
- 内层多文件 Tab / 分屏编辑
- 文件复制、移动、拖拽（新建 / 重命名 / 删除见 `files-tree-management.md`）
- 外部 LSP / 语言服务器 / 跳转定义跨文件工程级智能
- 左栏改为文件树或配置/文件双模切换
- 应用内三方合并编辑器（仍见 git-graph Out of Scope）
- 按 `.gitignore` **默认隐藏树展示**（明确不做；过滤尊重 gitignore 是另一回事，见 ADR-0009 / ADR-0027）
- 协作编辑、断线同步、文件锁定
