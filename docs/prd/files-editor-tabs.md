# files-editor-tabs

**Editor Tab 与分栏**

## Problem Statement

**Files Tab** 同一时刻只打开一个文件。改一处逻辑时我常要在三四个文件之间来回跳，⌘E 只能回到上一个，看不到自己开着哪几个；想左边改、右边对照另一个文件，只能另开一个预览窗口。可也有人就喜欢现在一次一个的轻，不想文件 Tab 变成 IDE。

## Solution

1. **偏好开关**：设置「偏好」新增「文件」组，勾选「启用编辑器标签页」，默认关。关着时一切与现在相同。
2. **Editor Tab**：开着时 Files 面板正文区最上面一排 **Editor Tab**。单击文件开在临时 Tab 里（斜体，下一次单击就替换它），改了内容或双击才固定成正式 Tab。
3. **左右两栏**：「向右分屏」或 ⌘\ 把正文分成左右两栏，每栏各有一排 Tab 和自己的工具栏；树里打开的文件进当前栏；同一个文件可以两栏都开，共用一份内容。
4. **键位**：⌘W 关当前 Tab，⇧⌘[ / ⇧⌘] 切上一个 / 下一个，⌘\ 向右分屏；项目 Tab 栏的键不变。
5. **三处同构**：项目的 Files Tab、服务器的 Files Tab、**Preview Window** 一起生效、规则一致。
6. **一套逻辑**：关掉开关 = Tab 上限为 1，不另写一套（ADR-0061）。

## User Stories

### 开关

1. 作为开发者，我想在设置里用一个开关决定要不要多个 Editor Tab，以便喜欢一次一个的人界面不变。
2. 作为开发者，我想这个开关默认关着，以便升级后什么都不变，想要的人自己打开。
3. 作为开发者，我想开关对项目、服务器的文件 Tab 和预览窗口一起生效，以便三处手感一致。
4. 作为开发者，我想打开开关时正在看的文件原样留下，以便不打断手头的事。
5. 作为开发者，我想关掉开关时只留下当前栏正在看的文件，其余自动关掉，服务器上没保存的先问我，以便不丢修改。

### Editor Tab

6. 作为开发者，我想单击树里的文件时它开在一个临时 Tab 里、再点别的文件就替换它，以便随手翻文件不会攒出一长排 Tab。
7. 作为开发者，我想一眼认出临时 Tab（文件名是斜体），以便知道它会被替换。
8. 作为开发者，我想改了内容、双击树里的文件（或在树上按 Enter）、双击临时 Tab 或在它的右键菜单里选「保持打开」时它就固定下来，以便正在弄的文件留着。
9. 作为开发者，我想再打开当前栏里已经开着的文件时直接切到那个 Tab，以便不出现重复的 Tab。
10. 作为开发者，我想 Tab 上有文件类型图标和文件名、颜色跟着 Git 状态（同文件树），同一栏里重名的文件后面带上级目录，以便分得清。
11. 作为开发者，我想悬停 Tab 看到它的相对路径，以便确认是哪个文件。
12. 作为开发者，我想点 `×` 关掉 Tab、关掉当前 Tab 后落到左边那个（没有就右边那个），以便和项目 Tab 栏的手感一致；也能用鼠标中键关，以便和 VS Code、WebStorm 的习惯一致。
13. 作为开发者，我想在 Tab 的右键菜单里关闭、关闭其他、关闭左侧、关闭右侧、全部关闭，以便一次清掉一批。
14. 作为开发者，我想在 Tab 的右键菜单里直接在文件夹中显示、在其他应用中打开、在终端中打开（服务器上为在 SSH 终端中打开、下载）、复制路径，以便不用先回文件树里找到它。
15. 作为开发者，我想拖动 Tab 调整顺序，拖到另一栏就移过去（那一栏先让出位置），拖动时 Tab 不会跑出这一排 Tab 的范围、按 Esc 可以放弃，以便自己排布、拖错了也能反悔。
16. 作为开发者，我想 Tab 多了可以横向滚动，当前 Tab 自动滚进视野，以便和项目 Tab 栏一样好用。
17. 作为开发者，我想用 ⌘W 关当前 Tab、⇧⌘[ / ⇧⌘] 切上一个 / 下一个（Windows / Linux 为 Ctrl+W、Ctrl+PageUp / Ctrl+PageDown），以便不碰鼠标。
18. 作为开发者，我想 ⌘W 永远关不掉 Files Tab 本身，以便不会误关常驻 Tab。
19. 作为开发者，我想关掉最后一个 Tab 时回到「在右侧选择文件」（预览窗口里用 ⌘W 关的则关窗），以便和现在的空态一致。

### 分栏

20. 作为开发者，我想点 Tab 行右端的「向右分屏」或按 ⌘\ 把当前文件在右栏再开一份，以便左右对照。
21. 作为开发者，我想两栏各有一排 Tab 和各自的工具栏、查找栏，以便每栏独立操作。
22. 作为开发者，我想点树里的文件、⌘E 最近打开、内容搜索和 Git 的「打开文件」都开进我最后操作的那一栏，以便另一栏留着不动。
23. 作为开发者，我想一眼看出哪一栏是当前栏，以便知道文件会开到哪里。
24. 作为开发者，我想同一个文件两栏都开时一边改另一边立刻跟着变、各看各的位置、各自撤销自己的改动，以便对照同一个长文件的两处。
25. 作为开发者，我想一栏编辑 Markdown、另一栏看它的预览，以便边写边看。
26. 作为开发者，我想拖动两栏之间的分隔线调整宽度、双击回到等分，以便按内容分配空间。
27. 作为开发者，我想一栏的最后一个 Tab 关掉后这一栏收起、另一栏占满，以便不留空栏。

### 与现有能力配合

28. 作为开发者，我想方向键切媒体时相邻的图片、PDF 开进临时 Tab，以便连续翻图不会刷出一排 Tab。
29. 作为开发者，我想切走、替换或关掉一个 Tab 时文本自动保存，以便和现在换文件时自动保存一样。
30. 作为开发者，我想文件被外部删除或在树里删掉时它的 Tab 静默关掉，改名或移动时 Tab 跟着新路径，以便不对着幽灵文件。
31. 作为开发者，我想重启后恢复打开的 Tab 和分栏（服务器的在连上后恢复），找不到的文件静默去掉，以便接着干活。
32. 作为开发者，我想服务器上有未保存修改的 Tab 名字旁有圆点，关掉它之前先问我；好几个都没保存时一次问完，以便不丢修改也不被连环弹窗。
33. 作为开发者，我想在预览窗口里也能开多个 Tab，用 ⌘W 关掉最后一个 Tab 时窗口一起关，以便一路 ⌘W 就能收尾，关着开关时也和原来一样一按关窗。
34. 作为开发者，我想在 Finder 里双击的文件已在某个预览窗口的树里时在那个窗口里成为一个 Tab，否则开一个预览窗口，以便一个文件夹只占一个窗口。
35. 作为开发者，我想预览窗口的标题跟着当前栏正在看的文件，以便分清多个窗口。

## Implementation Decisions

- **术语**：**Editor Tab** 见 CONTEXT.md；「栏」指 Files 面板正文区左右分出的一格，左栏、右栏，最后在其中点击、聚焦或打开过文件的那一栏是「当前栏」。决策见 ADR-0061。
- **模型**（纯函数，与界面分离）：面板 = 1–2 栏 + 当前栏；栏 = 有序 Tab 列表 + 当前 Tab；Tab = 路径 + 是否固定，每栏至多一个未固定的（临时 Tab）。上限 = 开关开着为不限，关着为 1。
  - **打开**：目标为当前栏。该栏已有此路径的 Tab → 激活它；否则有临时 Tab → 替换它的路径并激活；否则在当前 Tab 右侧新建临时 Tab。上限为 1 时唯一的 Tab 恒为临时，所以总是走替换。所有入口（树单击 / 双击、⌘E、内容搜索、Git「打开文件」、服务器的「前往路径」）都走这一个动作；树里双击或 Enter、双击 Tab、「保持打开」、拖到另一栏另带「固定」。
  - **固定**：改了内容（任何改动文档的编辑，含格式化）、上面几种显式动作。位置不够（上限 1）时不固定。
  - **关闭**：关当前 Tab 落到左邻、其次右邻；分栏时一栏的最后一个关掉即收起这一栏，另一栏成为当前栏；不分栏时关掉最后一个回空态。
  - **分栏**：只在上限允许且未分栏时可用；把当前栏的当前文件在右侧新栏开一个固定 Tab，新栏成为当前栏。拖 Tab 到另一栏 = 移过去（目标栏已有同一文件则激活那个、去掉被拖的）。
  - **开关只读两处**：上限，以及 Tab 行是否显示（开着就显示，关着不显示，不随 Tab 个数变）。
- **开关**：设置「偏好」在「Git」组之后新增「文件」组，只有一个勾选「启用编辑器标签页」，默认关，全局一份，存集中配置（ADR-0002）。从开到关：只留当前栏的当前 Tab 并让它成为临时，其余按关闭处理——本地先自动保存；服务器上有未保存修改的按「会丢修改前先问」，选「取消」则开关退回开着。从关到开：唯一的 Tab 原样成为临时 Tab。
- **布局**（开着时）：每栏从上到下是 Editor Tab 行（h-10，与右侧树顶栏对成一条线）→ 原有工具栏（面包屑 + 本栏动作，内容不变）→ 服务器的保存栏 → 查找栏 → 正文。Tab 行右端只有「向右分屏」，已分栏时不出。「显示文件树」在最右一栏工具栏的最右端。两栏之间是 `ui/resizable` 的可拖分隔（ADR-0053），每栏占 20%–80%（同其他分栏），比例全局一份，双击回等分。关着时没有 Tab 行，布局与现在相同。视觉见 DESIGN.md。
- **键位**（ADR-0013 的主进程拦截照旧）：主窗口激活 Tab 为 Files Tab、或焦点在预览窗口时——⌘W / Ctrl+W 关当前栏的当前 Tab，主窗口没有 Tab 可关时无效，预览窗口里关掉最后一个或本来就没有时关窗；⇧⌘[ / ⇧⌘]（Windows / Linux 为 Ctrl+PageUp / Ctrl+PageDown）在当前栏里切上一个 / 下一个，到头回绕；⌘\ / Ctrl+\ 向右分屏，已分栏时不起作用；上限为 1 时这两组键都不起作用。项目 Tab 栏的 ⌥⌘← / →、⌃Tab、⌘1…9 不变。设置「快捷键」的列表同步（`settings-keymap.md`）。
- **Tab 行交互**：溢出、滚轮横滚、激活时滚入视口同项目 Tab 栏。鼠标中键关闭——项目 Tab 栏有意不跟：关会话 Tab 会结束进程，中键误点的代价不同，关 Editor Tab 则不丢东西（本地自动保存、服务器先问）。
  - **拖动**：用 dnd-kit，按它多个列表互拖的做法——跟手的是浮层（不被 Tab 行的横向滚动裁掉，也不撑大滚动范围），落点处留出空位，看起来同终端 Tab 的拖动；Esc 取消。落点按指针：指针所在（或最近）的那一栏，取其中与浮层中心最近的 Tab。浮层仅水平，钳制在这一栏 Tab 实际占的那一段里（与可见的滚动区取交集，不含最后一个 Tab 之后的空白，同终端 Tab 钳制在组内），随滚动实时更新；指针进了另一栏，被拖的 Tab 才挪进那一栏的预览、让出位置（那一栏已开着同一个文件时不挪，松手并成那一个），松手才真正移动。
  - **右键菜单**：关闭 / 关闭其他 / 关闭左侧 / 关闭右侧 / 全部关闭 →（临时 Tab）保持打开 →（未分栏）向右分屏 /（已分栏）移到另一栏 → 在文件树中显示 + 文件本身的一组（同树右键菜单：本机为在文件夹中显示 / 在其他应用中打开 / 在终端中打开，预览窗口没有终端；服务器为在 SSH 终端中打开 / 下载…，断开期间不给下载，同正文菜单）→ 复制路径 /（本机）复制相对路径。
- **同一文件两栏**：共用一份文档，各有自己的视图；按 CodeMirror 官方 Split View 示例的做法，一边的改动带标记转发给另一边。转来的改动不进对方的撤销记录，所以各栏撤销的是自己在这一栏里的改动（见 ADR-0061）。自动保存、外部变更、冲突判定都按文件而不是按 Tab 做一次。
- **按栏各一份的视图状态**：阅读位置与查找按「栏 + 文件」各记一份，某栏第一次打开某文件时取它在任一栏里最近的那份；编辑 / 预览开关（Markdown / SVG / CSV）与左侧栏开关（PDF、PPT 的缩略图与 Markdown 预览的目录共用）每栏一个。仍是整个面板一份的：文件树显隐与展开、筛选、最近打开、类型筛选（预览窗口）。
- **方向键切媒体**：以当前栏的当前文件为起点，按可见树序取相邻的媒体文件，走「打开」（于是进临时 Tab；当前 Tab 已固定时在它右侧出现临时 Tab）。
- **保存与外部变更**（本地）：自动保存的时机加上「Tab 被切走、被替换、被关闭」，其余不变。文件被删除（外部或树里）→ 它在各栏的 Tab 静默关闭并从最近打开剔除；在树里删掉当前栏正显示的文件时，当前栏改开树上落点的文件（见 `files-tree-management.md`「删除后的落点」），不落到相邻 Tab；树里改名、移动 → Tab 跟着新路径。
- **服务器**：「会丢修改前先问」统一为「有未保存修改的 Tab 被替换或关闭之前」，外加原有的断开连接、改连接信息、移除服务器、退出；涉及多个文件时一个对话框列出文件名，按钮「全部保存 / 不保存 / 取消」。有未保存修改的 Tab 在 `×` 的位置显示圆点，悬停换回 `×`。保存栏每栏一条、显示本栏当前 Tab 的状态，⌘S 存当前栏的当前 Tab。「同一时刻只打开一个，新的打开取消旧的」仍按整台服务器算。手动断开再连上时与重启一样恢复 Tab 与分栏。
- **预览窗口**：系统带来的文件按根路由（见 `file-preview-window.md`「窗口模型」），落进已开窗口时固定打开为 Tab（关着「启用编辑器标签页」时照常替换当前的）；只有 ⌘W 关掉最后一个 Tab 时关窗（见「键位」），`×`、菜单或文件被删除关掉最后一个时回空态；窗口标题 = 当前栏当前 Tab 的文件名（空态为根文件夹名）；Tab 与分栏不落盘。
- **持久化**（项目与服务器）：上次打开路径换成「每栏 Tab 列表（路径、是否固定）+ 当前 Tab + 当前栏」；旧数据读成一个临时 Tab；按当前上限读入——上限为 1 时只取当前栏的当前 Tab、作为临时 Tab（没连上时关掉开关的服务器，下次连上即按此恢复）；恢复时找不到的路径静默去掉，一栏去空即收起。

## Testing Decisions

只测模型纯函数与契约，同一张表在上限「不限」与「1」下各跑一遍（先例：`files-tab.md` 的「构造输入 → 断言输出」）：

- **打开**：激活已有 / 替换临时 / 新建临时的位置；上限 1 时永远替换唯一的 Tab。
- **固定**：哪些动作固定；上限 1 时不固定。
- **关闭**：左邻其次右邻；一栏关空即收起、当前栏转给另一栏；不分栏关空回空态；关闭其他 / 左侧 / 右侧 / 全部。
- **分栏与移动**：未分栏才能分；跨栏移动遇到同一文件时合并。
- **开关切换**：开→关只留当前栏当前 Tab、返回要先问的服务器 Tab；关→开唯一 Tab 成为临时。
- **持久化形状**：旧形状读成一个临时 Tab；上限 1 时只读当前栏当前 Tab 且为临时；无效路径去掉、空栏收起。
- **删除与改名**：路径前缀匹配到的 Tab 关闭或换路径，不误伤同名前缀。
- **服务器先问**：给定 Tab 状态与动作 → 需要先问的文件列表。
- **键位匹配**：新增三个键按平台表驱动；预览窗口 ⌘W 在最后一个 Tab / 空态时关窗。

两栏视图同步、拖拽与布局人工回归，不写 e2e。

## Out of Scope

- 两栏以上、上下分栏。
- 跨窗口拖动 Tab、多个预览窗口合并。
- 钉在最左的 Tab（VS Code 的 Pin / Sticky）、Tab 数量上限与自动关闭最旧。
- Markdown 编辑与预览边滚边跟的同步（左右对照可以，滚动各自独立）。
- 快速打开（⌘P），仍见 `files-tab.md`。

## Further Notes

- 决策见 ADR-0061（一套模型、开关即上限），并修订 ADR-0005 的 ⌘W 规则；术语见 CONTEXT.md（**Editor Tab**、**Files Tab**）；视觉见 DESIGN.md。
- 关着开关时，⌘W 在主窗口的 Files Tab 上会关掉当前文件、回到空态（原先无效）；这是关着时唯一与原先不同的地方。
