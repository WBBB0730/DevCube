# ssh-server

**服务器与 SSH 终端**

## Problem Statement

我经常要登服务器看日志、部署、排查问题。现在要么切到终端手敲 `ssh`，要么另开 FinalShell / Termius / Xshell 这类软件，可市面上没有一个既轻又好用的 SSH 工具。DevCube 已经把本地项目、终端、Git 聚在一个面板里，唯独连服务器还得出门。我的服务器大多用密码登录，每次手输很烦；FinalShell 虽然能记密码，本身却又重又不顺手。

## Solution

左树新增一种与 **Project** 并列的顶层条目：**Server（服务器）**。一台 **Server** 就像一个远在别处的 **Project**：点开它，右侧是它的 **SSH Terminal** Tab，可以开多个。

- **连接照你的 ssh 配置**（ADR-0041，`docs/prd/ssh-connection.md`）：配置交给系统 OpenSSH 解析（`ssh -G`），连接由 DevCube 内置完成；用户已有的 `~/.ssh/config`、密钥、ssh-agent、跳板机、已知主机记录照样生效。
- **记住密码**：密码经 Electron safeStorage 加密后存放（加密密钥由系统钥匙串保管），连接时自动填上；首次连接的指纹确认、私钥口令、验证码等提问一律以 DevCube 弹窗回答。
- **与 Project 共用左树**：**Pin**、排序、拖拽、名称筛选全部复用；排序菜单新增「项目」「服务器」两项勾选，按类型筛选显示（数据源加入后为三类、三项勾选，见 `docs/prd/database.md`「左树」）。
- **断线不丢现场**：连接断开后 Tab 保留、报错留在原处，按回车原地重连；跨重启只恢复 Tab，不自动连接。
- **项目里也能连**：项目的新建终端菜单可直接「连接到服务器」，开出的同样是 **SSH Terminal**。
- **开着 TUN 代理也能连**（macOS / Windows）：给服务器打开「绕开代理直连」，连接就不经过代理、直接使用本机网络，不用改代理软件的规则（ADR-0039）。

远程文件管理（替代 WinSCP）是 **Server** 的另一个常驻 Tab（**Files Tab**），见 `docs/prd/server-files.md`。

## User Stories

1. 作为用户，我想从 `~/.ssh/config` 已有的主机里勾选添加 **Server**（可以一次勾多个），以便不用重复录入连接信息；同一台服务器真要登记多份也可以。
2. 作为用户，我想手填地址、用户名、端口、私钥和密码来添加 **Server**，以便连接那些没写进 `~/.ssh/config` 的服务器。
3. 作为用户，我希望 DevCube 只在自己的配置里记住 **Server**，不改写我的 `~/.ssh/config`。
4. 作为用户，我想 **Server** 和 **Project** 排在同一个左树列表里、图标不同，以便一眼区分又不用来回切换。
5. 作为用户，我想 **Server** 也能置顶、排序、拖拽重排、按名称筛选，规则与 **Project** 完全一致。
6. 作为用户，我想在排序菜单里勾选只显示「项目」或只显示「服务器」，以便条目多的时候聚焦其中一类。
7. 作为用户，我点开一台 **Server** 时，不想一点就自动连上、弹出要我输密码；它的 **Status Tab** 未连接时显示「连接」按钮（见 `docs/prd/server-status.md`）。
8. 作为用户，我想在一台 **Server** 下开多个 **SSH Terminal**（右键菜单「新建终端」或新建终端快捷键），以便同时看日志和敲命令。
9. 作为用户，我想连接时的提问（首次连接确认主机指纹、密码、私钥口令、验证码）都以 DevCube 弹窗出现，弹窗写明问的是什么，服务器给的提问原样显示。
10. 作为用户，我想在密码弹窗里勾选「记住密码」，下次连接时自动填上、不再弹窗。
11. 作为用户，当记住的密码已经不对时，我想看到弹窗提示我重新输入（可以顺便更新记住的密码），而不是一直拿错误的密码去试。
12. 作为用户，我想 **SSH Terminal** 断线后 Tab 保留，显示断开原因和退出代码，按回车就在同一个 Tab 里重连，以便看得到「连接被拒绝」「密码错误」这类原因。
13. 作为用户，我想重启 DevCube 后 **SSH Terminal** 的 Tab（名字和顺序）都还在，但处于已断开状态，按回车才连接，以便启动时不会一下子连一堆服务器、弹一堆提问。
14. 作为用户，我想编辑 **Server**：改名称、改手填的连接信息、修改或删掉记住的密码；来自 `~/.ssh/config` 的连接信息不在 DevCube 里改。
15. 作为用户，我想移除 **Server**，连到它的所有 **SSH Terminal**（包括开在项目里的）一并关闭，记住的密码一并删除。
16. 作为用户，我想在 **Project** 里新建终端时直接选一台 **Server** 连上，开出的 **SSH Terminal** 挂在项目的 Tab 栏里、行为与 **Server** 下的完全一致，以便不离开项目就能连服务器。
17. 作为用户，系统里找不到 `ssh` 时，我想在 Tab 里看到一句明确的中文提示，而不是莫名其妙的失败。
18. 作为用户，当系统没有可用的钥匙串（部分 Linux 桌面）时，我想看到「记住密码」不可用及原因，而不是让密码以接近明文的形式存下来。
19. 作为用户，我想在添加 / 编辑服务器时点「测试连接」，确认地址、端口、账号、密码都对了再保存；失败时看到明确的原因。
20. 作为用户，我想像项目一样给 **Server** 新建命令型配置（名称、命令、服务器上的工作目录、环境变量），比如 `tail -f` 日志、重启服务，以便一点就在服务器上执行。
21. 作为用户，我想服务器上的配置和项目配置一样可以运行、重跑、停止、拖拽排序，有状态点，运行输出在该服务器的 Tab 栏里。
22. 作为用户，我想在所有输密码的地方（服务器对话框、SSH 提问弹窗）能切换显示 / 隐藏，以便确认自己输对了。
23. 作为开着 TUN 模式代理的用户，我想给 **Server** 打开「绕开代理直连」，连接时不经过代理，以便不用改代理软件的规则。
24. 作为同时在用 VPN 的用户，我想只给需要的 **Server** 打开直连，以便只能经 VPN 访问的服务器照旧走 VPN。
25. 作为用户，打开直连后如果找不到本机网络、或查不到服务器的真实地址，我想看到明确的原因，而不是悄悄改回走代理。
26. 作为用户，我想像项目配置一样点工作目录旁的选择钮，直接在服务器上选目录，不必记住路径手打。

## Implementation Decisions

- **连接**：经内置连接（ADR-0041），做法见 `docs/prd/ssh-connection.md`；**SSH Terminal** 是连接上一个带伪终端的 shell 通道，与 **Terminal** 共用无头屏幕缓冲与输出管线。`ssh` 按登录 shell 环境的 PATH 查找（取第一个命中，Windows 补 `.exe`），与用户在终端里敲 `ssh` 找到的是同一个；Windows 上会不会落到 Git Bash 自带的那个取决于 PATH，待实测。
- **主机列表**：用成熟库 `ssh-config` 解析 `~/.ssh/config` 取出 Host 别名，跳过含通配符与取反的模式；`Include` 由 DevCube 展开（该库只做文本解析）。列表里展示的地址与用户以 `ssh -G <别名>` 的结果为准，与真正连接时一致；已添加过的主机标出「已添加」，仍可勾选。
- **提问与密码**：见 `docs/prd/ssh-connection.md`「认证」「提问弹窗」。若该 **Server** 有记住的密码，每次连接自动作答一次，被拒后弹窗重问（不拿错误的密码反复去试）；其余提问（主机指纹、私钥口令、验证码）一律弹窗。「记住密码」默认不勾，密码输错重问时保持上一次的选择。
- **密码存储**：用 Electron `safeStorage` 加密后存进集中配置（ADR-0002）；密码不以明文落盘，也不经命令行参数或环境变量传递。`safeStorage` 不可用，或 Linux 后端为 `basic_text` 时，不提供「记住密码」。
- **数据模型**：**Server** 记录名称、来源（`~/.ssh/config` 别名，或手填的地址 / 用户 / 端口 / 私钥路径）、添加时间、打开时间、是否置顶、自定义序、是否绕开代理直连（老档案缺省为否）；记住的密码单独存（键为服务器 id，只存密文），不随服务器列表下发渲染端。手填时名称可选（默认为「用户@地址」，端口不是 22 时带「:端口」），端口默认 22，私钥与密码可选。
- **重复登记**（ADR-0043）：同一连接目标（SSH 配置别名，或手填的地址、用户、端口与私钥；地址不分大小写）通常只登记一份，也允许登记多份：对话框里勾了已添加过的主机、手填或编辑成与已登记的相同时，不置灰任何按钮，点「添加 / 保存」时先弹确认（「“a”、“b” 已经添加过。仍要再添加一次吗？」/「“X” 连接的是同一台服务器。仍要添加吗？」），确认了照样登记；编辑时连接目标没改不问。只改地址大小写算没改：不问，也不断开已建立的连接。
- **编辑**：取消勾选「记住密码」再保存即删掉记住的密码。连接信息（连接目标、是否直连）变了才断开状态与文件连接，只改名或只改密码时不断开。
- **条目与自定义序**：左树条目键为 **Project** 的绝对路径、`server:<id>` 或 `datasource:<id>`（**Data Source**，见 `docs/prd/database.md`；绝对路径不会以这两个前缀开头，与 Tab 键的前缀约定同理）。三类条目共用一条自定义序：新登记的插到最前；拖拽松手后在「全部条目按当前规则排好的序列」里挪位，按类型筛掉的条目保留各自相对位置；**Pin** 时进入目标区块开头；老档案原有的自定义序原样保住。工作台现场（当前条目、每个条目的激活 Tab 与终端壳）按条目记，读档时迁移旧字段。
- **左树**：**Server** 行用 lucide `Server` 图标，与项目行一样有折叠箭头与配置区（只有命令型，没有「检测到的配置」）；hover 显示「更多」，右键菜单与之相同：新建终端、新建配置、编辑、置顶 / 取消置顶、移除。**Pin**、排序、拖拽、名称筛选沿用 `project-sort` 的规则，同时处理多类条目。新增 **Server** 与新增 **Project** 一样插到列表前部、自动选中并滚入视口。
- **排序菜单**：「固定置顶」下方加分隔线，再加「项目」「服务器」两项勾选（样式同「固定置顶」；数据源加入后多一项「数据源」）；只剩一项勾选时，该项不可取消。勾选状态随排序偏好一起持久化。
- **Tab 与工作台**：**Server** 的 Tab 栏没有 Git，常驻 Tab 为 **Status Tab**（见 `docs/prd/server-status.md`）与 **Files Tab**（见 `docs/prd/server-files.md`），其后是它的配置的 **Run Session** 与 **SSH Terminal**。激活 Tab 记忆、默认激活、关闭后回落的规则与 **Project** 一致。**SSH Terminal** 的壳（id、名称、顺序、所连 **Server**）按条目持久化，做法同 **Terminal** 壳（ADR-0008），恢复后是已断开状态。
- **SSH Terminal 生命周期**：连接结束后会话保留、Tab 不关，追加一行结束行，如「连接已断开，退出代码为 N。按回车重新连接」（形式参照 **Run Session** 的结束行，各情形见 `docs/prd/ssh-connection.md`）；按回车就在同一个 Tab 里重新连接；只有手动关闭 Tab 才销毁。与 **Terminal** 一样不计入退出确认。
- **项目里的 SSH Terminal**：项目右键菜单与 Tab 栏「+」菜单加「连接到服务器 ▸」子菜单，服务器按 `sortTreeEntries` 算出的左树顺序（含置顶分区）列出，不受左树按类型筛选的影响；开出的 Tab 与本地 **Terminal** 并列在项目 Tab 栏里，Tab 名为服务器名（同一处连同一台服务器的多个 Tab 按「prod / prod (2)」编号），壳随项目持久化。
- **移除 Server**：确认方式与移除 **Project** 一致；关闭所有连到它的 **SSH Terminal**，删除记录和记住的密码。
- **找不到 ssh**：连接时在 Tab 内输出中文提示。
- **服务器上的命令型配置**：属于某台 **Server**（**Project** 的命令型不变），字段同命令型：名称、命令、工作目录（服务器上的目录，`~` 开头可用，缺省即登录后的目录）、环境变量（在服务器端导出）；命令、工作目录与环境变量的值里可以留参数，每次运行前填值（`docs/prd/run-config-params.md`）。运行 = 经内置连接开一个带伪终端的 exec 通道执行命令串，命令串由远端登录 shell 按 POSIX sh 语法执行：先打印运行头（同 ADR-0023，由执行命令的 shell 打印；目录缺省显示 `~`），再 `cd`、`export`、执行命令，任一步失败即停。**Run Session** 语义不变（单实例、重跑先停旧的、停止即断开连接、结束行「进程已结束，退出代码为 N」），提问同样弹窗。编辑对话框沿用命令配置那一个；本机的目录选择器看不到服务器上的目录，工作目录旁的选择钮改为打开「选择服务器上的目录」对话框。移除 **Server** 时连同它的配置与运行会话一起删除。
- **选择服务器上的目录**：沿用这台服务器的文件连接（同 **Files Tab**）：打开即连接（已连上直接用），提问照常弹出，关掉对话框不断开；连不上或断开时框内显示原因与「重新连接」。树同 **Files Tab** 的文件树，只列目录；加载态同数据源的目录树（还没读到时在根的位置居中、或在子级位置出「正在读取…」，同一个目录同时只读一次）；树顶为「前往路径」（同 **Files Tab**，不存在或不是目录时就地提示）。打开时定位并选中工作目录里填的目录（没填或不可用时为家目录）；点目录即选中并开合。「选择」按本机配置的写法填回：家目录填成空（即登录后的目录），家目录之下写成 `~/…`，其余为绝对路径。Esc、点遮罩即取消，只关它自己；叠着 SSH 提问时 Esc 先关提问。
- **测试连接**：添加 / 编辑对话框底栏左侧「测试连接」：用表单当前的连接目标经内置连接登录，认证通过即断开；是否直连按表单当前的勾选。测试只检验表单里的内容：密码不弹给用户——表单里填了密码就用它作答一次，没填时勾着「记住密码」才用记住的；密码被拒、或根本没有密码时立即结束认证（不再试别的，免得在服务器上多记失败次数），结果为「密码错误」或「服务器要求输入密码，请先填写后再测试」。其余提问（主机指纹、私钥口令、验证码）照常弹窗；测试本身不记住密码与私钥口令。结果「连接成功」/「连接失败」显示在按钮右侧同一行，失败时另弹错误框显示原因（如「无法连接到 X：连接被拒绝」）。同一时刻只测一个，新测试取消旧的；对话框关闭即取消。添加时只能测一台：手填的那台，或只勾了一台的 SSH 配置主机。
- **绕开代理直连**（ADR-0039，仅 macOS / Windows）：每台 **Server** 各有一个开关，添加时默认不勾，没有全局设置；Linux 上不显示，已存的值也不生效。连接时按该服务器的开关（测试连接按表单当前的勾选）决定是否直连：绑定实体网卡的 IPv4 地址，目标是域名时向实体网卡所在网络的 DNS 查出真实地址改连，known_hosts 仍按原主机名核对；生效配置里有 `ProxyJump`、`ProxyCommand`、`BindAddress` 或 `BindInterface` 时不插手。查不到时不连接、不退回经代理连接：**SSH Terminal** 与 **Run Session** 的结束行、测试连接的失败结果写明原因（「无法直连：未找到可用的本机网络」/「无法直连：未能解析 X 的真实地址」）。

## Testing Decisions

沿用项目约定：只测纯函数，零 mock。

- `~/.ssh/config` 里可直接连接的别名：跳过通配符与取反模式。（`Include` 展开与读文件在 IO 层，不在单测范围）
- `ssh -G` 输出解析；`ssh -G` 的目标参数（含以 `--` 结束选项）与手填目标校验。
- 认证与提问的决策：见 `docs/prd/ssh-connection.md`「Testing Decisions」。
- 混合条目的排序、Pin 分区、名称筛选、按类型筛选；拖拽挪位（被筛掉的条目保住相对位置）；Pin 进入目标区块开头。
- **Server** 条目的 Tab 序与默认激活：常驻的 **Status Tab** 在前，有运行中的会话时它优先（见 `docs/prd/server-status.md`）。
- **SSH Terminal** 壳的合并与落盘、旧工作台字段的迁移。
- 在 PATH 里找 `ssh`。
- 服务器上执行的命令串（运行头、`~` 目录、环境变量与单引号转义）；ssh 报错说明的提取。
- 选中的目录填回工作目录的写法（家目录、家目录之下、同前缀的兄弟目录、家目录是根时）。
- 树行里的「正在读取…」（只出在正在读、还没读到的已展开目录下，根还没读到时在第 0 层）。
- 绕开代理直连：按 `ssh -G` 结果判断是否插手；`scutil` 输出与 Windows 网卡查询结果的解析。

落在 `src/shared/server.test.ts`、`ssh-config.test.ts`、`tree-entry.test.ts`、`project-sort.test.ts`、`workspace.test.ts`、`tab-activation.test.ts`、`renderer-bootstrap.test.ts`、`server-files.test.ts`、`files-tree-flatten.test.ts` 与 `src/main/command.test.ts`、`ssh-direct.test.ts`。不写 UI / e2e 测试。

- 待实测：Windows 上系统 OpenSSH 是否默认可用；与 Git Bash 自带 `ssh` 的取舍。
- 待实测：Linux 上 `safeStorage` 后端的判定。
- 已实测（macOS 15.7、Clash Verge Rev + mihomo 的 TUN 模式、fake-IP）：照常连接时 TCP 连得上，但在收到服务器问候前就被断开，域名经系统解析得到 `198.18.x.x` 假地址；绑定 en0 的地址后能收到问候；同一个 DNS（`scutil --dns` 里限定到 en0 的那组，路由器 DNS 同样可行）不绑定时答假地址，绑定后答真实地址；TUN 开着时 `PrimaryInterface` 仍是 en0。经系统 `ssh` 加上 `BindAddress` / `HostName` / `HostKeyAlias` 连 `git@github.com` 能进入认证，主机指纹按原主机名记入 known_hosts；查网卡与真实地址约 50ms。
- 待实测：Windows 上绑定实体网卡地址能否绕开 TUN，以及 PowerShell 查询实体网卡与 DNS 的结果。

## Out of Scope

- 远程文件管理（替代 WinSCP）：另行立项，见 `docs/prd/server-files.md`。
- 端口转发、隧道、SOCKS 代理的管理。
- **Server** 分组、多台批量执行命令。
- 自己解析 `~/.ssh/config` 取连接配置（一律交给 `ssh -G`，见 ADR-0041）。
- 改写 `~/.ssh/config`；在 DevCube 里编辑来自 `~/.ssh/config` 的连接参数。
- 手填 **Server** 的跳板机等高级选项：需要的话写进 `~/.ssh/config`。
- 自动重连、心跳保活设置。
- 从 FinalShell / Termius 等软件导入服务器列表。
- 在线状态、延迟探测。
- 生成密钥、把公钥装到服务器上（`ssh-copy-id`）。
- 「无项目」：另行立项。
- Linux 上绕开代理（普通进程做不到，见 ADR-0039）；自动识别「被代理拦截」并自动改直连；直连时的 IPv6 目标。
