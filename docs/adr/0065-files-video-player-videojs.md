# Files Tab 视频预览用 Video.js v10 搭自绘播放器，全屏整个播放器

视频原先用 Chromium 原生 `<video controls>`。按住 → 倍速时要在画面里显示倍速标记，全屏时也要显示；但原生控件的全屏是让视频元素本身全屏，全屏时页面上别的东西都不画，标记无从显示。要全屏一个包住视频与标记的外层，原生控件栏上的全屏钮又改不了。所以视频也换成自绘控件，操作栏与音频共用一套（播放、时间、倍速、循环、音量），视频多一颗全屏钮。

播放器外壳用 [Video.js v10](https://videojs.org)（`@videojs/react`）：Vidstack、Media Chrome、Plyr 的作者 2026 年合到 Video.js 重写成 v10，10 月正式发布，Vidstack 已标为弃用、Media Chrome 已并入 Video.js，网页播放器的主流方案就是它。我们只用它不带样式的部件：播放器外层（全屏对象，先全屏外层、不支持时退回视频本身）、控件显隐（播放中鼠标静止即隐去，暂停常显）、进度条（拖动时画面跟着走、已缓冲段）、单击与双击手势。操作栏的钮与音频共用我们自己的写法，直接读写媒体元素；Video.js 自带的外观与快捷键都不用，快捷键仍走 Files 的音视频快捷键。

叠在画面上的进度条、操作栏与倍速标记用 CSS 锚点定位贴住视频元素本身：播放器外层铺满预览区（全屏时铺满屏幕），视频按比例居中，叠层跟着画面而不是跟着留白。锚点名用 `anchor-scope` 限定在单个播放器内，分栏里同时开两个视频互不干扰。

## Considered Options

- **保留原生控件，隐藏它的全屏钮，改由 F 键与双击全屏外层**：改动最小，但控件栏上少了全屏钮，鼠标用户不容易发现怎么全屏。
- **保留原生全屏钮**：F / 双击进入的全屏有标记，点钮进入的全屏没有，同一功能两种表现。
- **不用库，照音频播放条手写**：控件显隐计时、进度条拖动、全屏回退、读屏属性都要自己写，正是库已经做好的部分。

## Consequences

- 叠层上的控件一律白色、与主题无关（画面明暗不定）：在叠层上就地改写操作栏用到的颜色变量，钮、读数与滑杆的写法与音频一致。
- 倍速下拉挂在播放器外层里而不是 body 上：全屏时只有全屏元素内的东西可见。为此下拉菜单组件加了「挂载处」参数。
- 库很新（正式发布约两个月，几乎每周一版），升级时留意部件接口的变化；用到的只有上面几样部件。
- 播放中打开倍速下拉后鼠标不动，叠层仍会按时隐去，下拉留在原处；暂不处理。
